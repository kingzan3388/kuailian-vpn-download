## 二、核心概念

### 2.1 概念定义

**快连VPN（Kuai Lian VPN）** 是一种基于隧道协议（Tunneling Protocol）的加密通信服务，专为安卓操作系统优化。它通过在您的设备与目标服务器之间建立一条加密的“虚拟隧道”，将您的网络流量通过隧道传输，从而：
- **隐藏真实IP地址**：您的公网IP被替换为VPN服务器的IP，防止网络追踪。
- **加密数据传输**：使用AES-256-GCM等军用级加密算法，确保数据在传输过程中不被窃听或篡改。
- **突破地理限制**：通过选择不同国家/地区的服务器节点，访问被地域封锁的内容（如流媒体、社交媒体等）。

- 内置**DNS泄漏防护**：自动检测并阻止DNS查询被第三方拦截。

### 2.2 工作原理

快连VPN的工作原理可分解为以下四个关键步骤：

1. **连接建立**：用户在安卓客户端输入服务器地址（如 `hk-01.kuailian.com`）并触发连接。客户端与服务器通过**TLS 1.3**握手，交换加密密钥。
2. **隧道封装**：所有出站数据包（如HTTP请求、DNS查询）被封装成加密数据包。例如，一个普通的GET请求会被转换为：
   ```
   原始数据: GET /index.html HTTP/1.1
   加密后: 0x7A3F... (AES-256加密)
   ```
3. **路由转发**：加密数据包通过UDP（默认）或TCP端口发送至VPN服务器。服务器解密后，将原始请求转发至目标网站，并将响应数据加密后返回客户端。
4. **IP伪装**：目标网站看到的是VPN服务器的IP地址（如日本东京节点 `103.235.xxx.xxx`），而非您的真实IP。

**安全模型**：快连VPN采用**零日志（Zero-Log）** 政策，服务器端不存储任何连接日志、流量日志或时间戳。2026新版还引入了**前向保密（Perfect Forward Secrecy）** 机制，即使长期密钥泄露，也无法解密历史通信。
