## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）**：一种在公共网络（如互联网）上建立加密隧道的技术。通过VPN，用户的设备与远程VPN服务器之间建立一条安全、加密的连接。所有进出设备的数据都会经过这条隧道，从而防止第三方（如ISP、黑客、政府机构）窃听或篡改。VPN的核心功能包括：
- **加密通信**：使用强加密协议（如AES-256）保护数据。
- **IP隐藏**：将用户的真实IP替换为VPN服务器的IP，实现匿名访问。
- **地理解锁**：通过选择不同地区的服务器，绕过内容限制（如流媒体、社交媒体）。

### 2.2 工作原理

快连VPN的工作原理基于现代VPN协议栈，主要涉及以下几个关键技术环节：

2.  **隧道建立**：当用户点击“连接”按钮时，客户端会向快连服务器发起握手请求。服务器验证用户凭据（如账号、订阅状态）后，通过密钥协商建立一个加密隧道。此过程通常耗时不到1秒。
3.  **数据封装与转发**：用户的所有网络数据包（如HTTP请求、DNS查询）被封装成加密数据包，通过隧道发送到VPN服务器。服务器解密后，将原始数据包发送到目标网站。响应数据沿相同路径返回，再次加密后由客户端解密。
4.  **IP伪装与DNS保护**：VPN服务器使用自己的IP地址作为源IP，隐藏用户真实IP。同时，DNS查询也会通过VPN隧道转发，避免DNS泄露（即ISP或第三方DNS服务器记录用户访问记录）。
