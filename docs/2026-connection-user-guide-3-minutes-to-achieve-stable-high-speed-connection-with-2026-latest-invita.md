## 二、核心概念

### 2.1 概念定义

在深入使用快连之前，有必要明确几个核心概念：

*   **网络延迟 (Latency)**：指数据从源头发送到目的地并收到响应所需的时间，通常以毫秒(ms)为单位。低延迟对于实时交互（如视频会议、在线游戏）至关重要。
*   **网络抖动 (Jitter)**：指网络延迟随时间变化的程度。高抖动会导致音画不同步、游戏卡顿。
*   **丢包率 (Packet Loss)**：指在传输过程中丢失的数据包占总发送数据包的比例。丢包会导致数据重传，严重影响连接质量。
*   **带宽 (Bandwidth)**：指单位时间内网络能够传输的最大数据量，通常以Mbps（兆比特每秒）为单位。高带宽保障了大文件下载和4K/8K流媒体的流畅播放。
*   **节点 (Node)**：快连在全球部署的服务器，用户通过连接到这些节点来优化网络路径。节点的选择直接影响连接质量。
*   **协议 (Protocol)**：快连使用的网络传输协议，如TCP、UDP、以及基于TLS/HTTPS的加密协议。不同的协议在稳定性和穿透性上各有优劣。
