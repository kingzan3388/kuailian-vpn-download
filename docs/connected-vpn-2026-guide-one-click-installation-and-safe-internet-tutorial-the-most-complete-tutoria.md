## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）** 是一种通过公共网络（如互联网）建立加密隧道，将用户设备与远程服务器连接的技术。它主要实现两个核心功能：**数据加密**和**IP地址伪装**。

- **数据加密**：当您的设备通过VPN发送数据时，所有信息（如网页请求、聊天内容、登录密码）都会被转换为不可读的密文，防止黑客、ISP（互联网服务提供商）或监控机构窃取。
- **IP地址伪装**：VPN会为您分配一个位于服务器所在地区的虚拟IP地址，从而隐藏您的真实地理位置。例如，您在中国大陆使用位于美国的VPN服务器，访问美国网站时，网站会认为您来自美国。

**快连VPN** 在此基础上，进一步优化了连接速度、协议兼容性和用户界面，特别针对苹果系统的“Network Extension”框架进行了适配，确保在iOS和macOS上实现低延迟、高稳定性的连接。

### 2.2 工作原理

快连VPN在苹果设备上的工作流程可以分为以下几个关键步骤：

1. **连接建立**：用户打开快连VPN应用，选择一个服务器节点（如“日本东京”或“美国洛杉矶”）。应用向该服务器发起一个加密握手请求，通过**IKEv2/IPSec**、**WireGuard**或**OpenVPN**等协议建立安全隧道。
2. **流量重定向**：一旦隧道建立，苹果设备的系统网络栈会将所有出站流量（包括浏览器、邮件、即时通讯等应用的请求）通过虚拟网络接口（如`utun`接口）转发到VPN应用。
3. **数据封装与加密**：快连VPN应用将原始数据包封装在加密层中，添加新的IP头部（显示为VPN服务器的IP地址），然后通过互联网发送给VPN服务器。
4. **服务器转发与解密**：VPN服务器收到加密数据包后，使用预先共享的密钥解密，恢复原始数据包，并将其发送到目标网站或服务（如Google、YouTube）。同时，服务器将目标服务器的响应数据以同样方式加密后回传给您的设备。
5. **本地解密与呈现**：您的苹果设备收到加密响应后，通过VPN应用解密，最终呈现为网页内容或应用数据。

值得注意的是，苹果系统从iOS 15/macOS Monterey起，对VPN应用实施了更严格的**按需连接**（On-Demand）和**分隧道**（Split Tunneling）控制。快连VPN在2026版本中充分利用了这些特性，允许用户指定哪些应用走VPN、哪些直连，从而在保障隐私的同时减少不必要的流量损耗。

### 3.3 高级技巧

**1. 分隧道设置（Split Tunneling）**
- **用途**：让国内应用（如微信、支付宝）走直连，国外应用（如Google、Twitter）走VPN，避免国内服务因VPN而卡顿。
- **操作**：在快连VPN应用设置中，找到“分隧道”或“应用路由”选项。选择“仅以下应用走VPN”，然后勾选需要加密的应用（如Chrome、YouTube）。注意：部分旧版iOS可能不支持此功能。

**2. 协议切换**
- **WireGuard**：速度最快，但部分网络（如校园网）可能封锁其UDP端口。若连接失败，可在设置中切换为**IKEv2**（TCP端口，兼容性最好）或**OpenVPN**（自定义性强，但速度稍慢）。
- **操作**：进入应用“设置” -> “协议”，选择“WireGuard”、“IKEv2”或“OpenVPN”。

**3. 自动连接与按需连接**
- **按需连接**：在“设置” -> “通用” -> “VPN与设备管理” -> 点击快连VPN配置右侧的“i”图标，开启“按需连接”。这样，当您访问被屏蔽的网站时，系统会自动触发VPN连接，无需手动操作。
- **自动重连**：在快连VPN应用内开启“自动重连”功能，当网络中断后，应用会在3秒内尝试恢复连接。

**4. 自定义DNS**
- 为防止DNS泄露，建议在应用设置中启用“自定义DNS”，输入Cloudflare的`1.1.1.1`或Google的`8.8.8.8`，以绕过ISP的DNS劫持。

## 四、常见问题FAQ

**Q1：为什么我在App Store搜索不到“快连VPN”？**
- **A**：快连VPN应用已从部分地区的App Store下架。请确保您已登录**非中国大陆地区的Apple ID**（如美区、港区）。如果仍然搜索不到，请直接访问官网`https://www.kuailiansj.com`，通过企业描述文件方式安装。

**Q2：安装描述文件时提示“未受信任的开发者”，怎么办？**
- **A**：这是苹果的安全机制。请前往“设置” -> “通用” -> “VPN与设备管理” -> 找到快连VPN描述文件，点击“信任此开发者”。之后返回安装即可。注意：仅信任来自官网的描述文件。

**Q3：连接成功后，为什么部分应用（如淘宝、微博）无法打开？**
- **A**：这是因为您的VPN节点位于国外，导致国内应用服务器拒绝了来自海外IP的请求。解决方法：开启**分隧道**功能，将国内应用排除在VPN之外；或者切换至“香港”或“台湾”节点，这些节点对国内服务兼容性较好。

**Q4：VPN连接频繁断开，如何解决？**
- **A**：可能原因及解决方案：
  1. **网络不稳定**：切换至4G/5G移动网络或重启路由器。
  2. **协议被干扰**：在应用设置中将协议从“WireGuard”切换为“IKEv2”（使用TCP端口，更稳定）。
  3. **设备后台限制**：在“设置” -> “通用” -> “后台应用刷新”中，确保快连VPN的开关是开启状态。

**Q5：使用快连VPN会消耗大量手机流量吗？**
- **A**：VPN加密过程会增加约5%-15%的流量开销（因为数据包头部和加密元数据）。例如，观看1小时1080p视频（约1GB流量），VPN实际消耗约1.1-1.15GB。这是正常现象。建议在Wi-Fi环境下使用流媒体服务。

**Q6：如何确认我的VPN连接没有泄露我的真实IP？**
- **A**：在连接VPN后，访问IP检测网站（如`ipleak.net`），查看显示的IP是否与您选择的服务器一致。同时，检查WebRTC泄露：在Chrome地址栏输入`chrome://webrtc-internals`，查看“localIP”字段是否暴露了您的真实IP。快连VPN默认已阻止WebRTC泄露。

**Q7：快连VPN支持多少台设备同时连接？**
- **A**：标准套餐支持**5台设备**同时在线。如果您拥有多台苹果设备（如iPhone、iPad、Mac），只需在所有设备上登录同一账号即可。注意：超出5台后，最早连接的设备会被自动踢下线。
