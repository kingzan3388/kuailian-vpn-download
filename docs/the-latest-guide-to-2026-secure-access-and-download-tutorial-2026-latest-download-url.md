## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）**：一种通过公共网络（如互联网）建立加密隧道，实现远程安全访问私有网络资源的技术。简单来说，VPN会在您的设备与目标服务器之间创建一个加密的“隧道”，所有通过该隧道传输的数据都会被加密，从而防止第三方（如黑客、ISP、政府机构）窃听或篡改。

**快连VPN（QuickConnect）**：一款专为跨国网络访问设计的VPN服务。与传统VPN相比，它更注重用户的连接速度与稳定性，并采用先进的传输协议（如WireGuard、Shadowsocks、V2Ray）来应对复杂的网络封锁。快连的核心优势在于“一键连接”和“智能分流”，用户无需手动配置复杂的代理规则，即可实现流畅访问全球资源。

### 2.2 工作原理

快连VPN的工作原理基于客户端-服务器模型。当用户通过客户端发起连接请求时，系统会执行以下步骤：

1. **身份认证**：客户端向服务器发送加密的认证信息（如账号密码或订阅链接），服务器验证通过后，建立安全通道。
2. **隧道建立**：使用先进的加密协议（如AES-256-GCM）在用户设备与快连服务器之间构建一条虚拟隧道。所有网络流量都会被封装在隧道内传输。
3. **数据加密与转发**：用户的网络请求（如访问Google、YouTube、Netflix）被加密后发送至快连服务器，服务器解密请求后，以服务器的IP地址作为源IP，向目标网站发起访问。目标网站返回的数据再通过隧道加密返回给用户。
4. **智能分流**：快连内置了“全局模式”和“智能模式”。在智能模式下，系统会自动识别国内与国外流量：国内流量（如访问百度、淘宝）直连，不经过VPN隧道，保证速度；国外流量（如访问ChatGPT、Twitter）则走加密隧道，突破封锁。
