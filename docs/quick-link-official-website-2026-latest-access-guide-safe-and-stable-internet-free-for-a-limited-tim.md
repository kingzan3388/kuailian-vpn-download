## 二、核心概念

### 2.1 概念定义

在深入使用快连之前，理解其背后的核心概念至关重要。快连本质上是一种**虚拟专用网络（VPN，Virtual Private Network）** 服务。VPN是一种在公共网络（如互联网）上建立加密连接的通信技术。它通过在用户设备与远程服务器之间创建一个安全的“隧道”，使得所有进出用户设备的数据都经过加密传输，从而隐藏用户的真实IP地址，并模拟出服务器所在地区的网络身份。

与传统的点对点VPN不同，快连采用了更现代化的**混合代理架构**，结合了**传输层安全协议（TLS）** 与**自定义加密协议**。这意味着它不仅能像传统VPN一样加密整个网络流量，还能通过智能路由技术，仅对需要访问特定资源的流量进行代理，从而在保证安全性的同时，极大提升国内网络访问（如访问视频网站、本地服务）的速度。此外，快连还集成了**智能DNS解析**功能，能够自动识别并绕过DNS污染，确保域名解析的正确性。

### 2.2 工作原理

快连的工作流程可以抽象为以下几个关键步骤，理解这一过程有助于您更好地使用和排错：

1.  **客户端启动与握手**：当您在设备上启动快连客户端后，它会首先尝试连接至快连的**控制服务器**（通常位于海外）。这个过程类似于一次“握手”，客户端会发送一个包含加密身份验证信息的请求，控制服务器验证您的账号有效性（如订阅状态、设备数量）后，会分配一个**最优的接入节点**列表。

2.  **隧道建立**：客户端根据算法（如延迟最低、负载最小）选择一个接入节点，并与之建立一个加密的**TLS/SSL隧道**。这个隧道是安全通信的基石，所有后续的互联网流量都会通过此隧道传输。快连使用了**AES-256-GCM**等高级加密标准，确保数据即使被截获也无法被解读。

3.  **流量路由与代理**：一旦隧道建立，您的设备就会将本地网络配置修改为通过快连的虚拟网卡进行通信。当您访问一个网站（例如`www.google.com`）时，数据包首先被快连的虚拟网卡捕获。客户端根据预设的**路由规则**（例如“全局模式”或“分流模式”）判断：如果目标地址在“代理列表”中，数据包就会被加密并发送至快连接入节点；如果目标地址在“直连列表”中（如访问国内银行网站），数据包则不经过代理，直接通过本地网络发送。

4.  **数据解密与转发**：快连的接入节点接收到加密的数据包后，使用私钥进行解密，还原出原始的HTTP/HTTPS请求。然后，节点以自身的IP地址（而非您的真实IP）向目标服务器发送请求。目标服务器响应后，数据流经反向路径：节点加密响应数据，通过隧道传回您的客户端，客户端解密后呈现给您。这样，您的真实IP地址和网络活动就得到了完全隐藏。
