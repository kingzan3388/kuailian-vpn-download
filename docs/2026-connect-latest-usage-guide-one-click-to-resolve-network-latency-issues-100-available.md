## 二、核心概念

### 2.1 概念定义

**网络延迟**（Network Latency）指数据从源节点传输到目标节点所花费的时间，通常以毫秒（ms）为单位。高延迟会导致数据包传输缓慢，进而引发视频缓冲、游戏卡顿、网页加载缓慢等问题。延迟的成因包括物理距离、网络拥塞、路由器处理能力不足、以及互联网服务提供商（ISP）的限速策略。

**快连**（Kuailian）是一个基于代理协议（Proxy Protocol）和隧道技术（Tunneling）的网络优化工具。它通过建立加密的虚拟专用通道（Virtual Private Channel），将用户的数据流量重新路由至最优服务器节点，从而绕过拥堵的公共网络路径，显著降低延迟。与传统的VPN（虚拟专用网络）不同，快连专注于延迟优化而非单纯的数据加密，其核心算法能够动态选择延迟最低的节点。

### 2.2 工作原理

快连的工作原理可概括为“智能路由+动态节点选择”。具体流程如下：

1. **流量捕获**：当用户启动快连后，软件会在操作系统层面创建一个虚拟网络接口（Virtual Network Interface），捕获所有出站流量。
2. **延迟测量**：快连内置的延迟探针（Latency Probe）会持续监测全球数百个服务器节点的实时延迟、丢包率（Packet Loss Rate）和带宽利用率（Bandwidth Utilization）。
3. **路径优化**：基于测量数据，快连的路径选择算法（Path Selection Algorithm）会计算从用户到目标服务器（如游戏服务器、视频流服务器）的最优路径。该算法综合考虑了物理距离、网络拓扑和当前拥塞状态，选择延迟最低且稳定的节点。
4. **数据封装与转发**：用户的数据包被封装在加密隧道中，通过所选节点转发至目标服务器。加密过程使用AES-256-GCM（高级加密标准-256位-Galois/Counter模式）算法，确保数据安全性。
5. **回程优化**：返回的数据同样经过最优节点处理，确保双向延迟均得到优化。

此外，快连支持多协议兼容（如WireGuard、Shadowsocks、V2Ray），用户可根据自身网络环境选择最适合的协议。例如，WireGuard适用于低延迟场景，而V2Ray则更适合需要绕过复杂防火墙的环境。

## 三、使用指南

### 3.1 安装配置

#### 系统要求
- **操作系统**：Windows 10/11（64位）、macOS 11 Big Sur及以上、Linux（Ubuntu 20.04+/CentOS 7+）、iOS 14+、Android 8.0+
- **硬件**：至少1GB RAM，50MB可用磁盘空间
- **网络**：稳定的互联网连接

#### 安装步骤（以Windows为例）
1. **下载安装包**：访问快连官方网站 [https://www.kuailiansj.com](https://www.kuailiansj.com)，点击“下载客户端”按钮，选择Windows版本。
2. **运行安装程序**：双击下载的`Kuailian_Setup_x64.exe`，在弹出的用户账户控制（UAC）提示中选择“是”。
3. **自定义安装路径**：建议保持默认路径`C:\Program Files\Kuailian`，或点击“浏览”选择自定义目录。
4. **完成安装**：安装完成后，勾选“立即启动快连”，点击“完成”。

#### 初始配置
1. **注册/登录**：启动快连后，点击“注册账号”，输入邮箱和密码完成注册。已有账号则直接登录。
2. **选择套餐**：快连提供免费试用（7天，限速10Mbps）和付费套餐（月付、年付）。建议先试用评估效果。
3. **协议选择**：在“设置”->“协议”中，推荐选择“智能模式”（Smart Mode），系统将自动匹配最佳协议。
4. **节点列表**：点击“节点列表”，系统会显示全球节点（如香港、东京、洛杉矶等）。选择延迟最低的节点（通常显示绿色标记）。

### 3.2 基本用法

#### 一键连接
1. **启动客户端**：双击桌面“快连”图标，打开主界面。
2. **点击连接**：在主界面中央，点击“一键加速”按钮。系统会自动选择最优节点并建立连接。
3. **验证连接**：连接成功后，界面显示“已连接”，并显示当前延迟（如“延迟：35ms”）。您可使用`ping`命令测试：在命令提示符中输入`ping 8.8.8.8`，观察延迟是否降低。

#### 手动选择节点
1. 点击“节点列表”选项卡。
2. 查看各节点的延迟、丢包率和带宽状态（绿色=优，黄色=中，红色=差）。
3. 双击目标节点（如“香港-01”），等待连接建立。

#### 断开连接
- 在主界面点击“停止加速”按钮，或右键点击系统托盘图标选择“断开连接”。

### 3.3 高级技巧

#### 1. 自定义路由规则
快连支持“分应用代理”（Split Tunneling），允许您指定哪些应用程序通过快连加速，哪些使用本地网络。
- 操作路径：设置 -> 高级设置 -> 分应用代理。
- 例如：添加“steam.exe”和“chrome.exe”，确保游戏和浏览器流量通过快连，而下载软件（如迅雷）使用本地网络，避免占用带宽。

#### 2. 多协议切换优化
在特定网络环境下，切换协议可进一步提升性能：
- **WireGuard**：适用于低延迟、高带宽场景（如在线游戏）。
- **Shadowsocks**：适用于需要绕过UDP（用户数据报协议）限制的环境（如某些企业网络）。
- **V2Ray**：适用于高度审查的网络（如校园网或特定国家防火墙）。
- 切换方法：设置 -> 协议 -> 选择目标协议 -> 重启快连。

#### 3. 端口转发（Port Forwarding）
用于特定应用（如远程桌面、P2P下载）需要固定端口的情况：
1. 设置 -> 高级设置 -> 端口转发。
2. 点击“添加规则”，输入本地端口（如3389）和远程端口（3389）。
3. 保存后，外部设备可通过快连节点的IP访问您的本地服务。

#### 4. 命令行操作（高级用户）
快连提供CLI（命令行界面），适合脚本自动化：
```bash
# 启动快连并连接至东京节点
kuailian connect --node tokyo-01 --protocol wireguard

# 查看当前状态
kuailian status

# 断开连接
kuailian disconnect
```

## 四、常见问题FAQ

**Q1：快连连接后，为什么网络反而变慢了？**  
A：可能原因包括：1) 所选节点当前负载过高（显示为红色）；2) 本地网络本身存在严重丢包；3) 协议不兼容。建议尝试：切换到“智能模式”让系统自动选择节点；或更换为WireGuard协议。若问题持续，可联系客服检查服务器状态。

**Q2：快连支持哪些操作系统？**  
A：支持Windows、macOS、Linux、iOS和Android。移动端可在应用商店搜索“快连”下载。注意：iOS版需使用非中国区Apple ID下载。

**Q3：免费试用期结束后，如何续费？**  
A：登录官网 [https://www.kuailiansj.com](https://www.kuailiansj.com)，进入“用户中心”->“我的订单”，选择月付（$9.99/月）或年付（$79.99/年，省30%）。支持支付宝、微信、PayPal支付。

**Q4：快连会记录我的浏览历史吗？**  
A：不会。快连采用严格的“无日志策略”（No-Log Policy），仅记录连接时间、流量大小等匿名数据以优化服务，不存储任何用户浏览内容或DNS请求。详情可查看隐私政策页面。

**Q5：如何解决快连与杀毒软件的冲突？**  
A：部分杀毒软件（如360、卡巴斯基）可能会误报快连的虚拟网卡驱动。解决方法：1) 将快连安装目录添加至杀毒软件白名单；2) 关闭“网络防火墙”或“数据包过滤”功能。若仍有问题，可切换至“兼容模式”（设置->高级设置->兼容模式）。

**Q6：快连能否用于游戏加速？**  
A：完全可以。快连针对游戏场景优化了UDP转发和低延迟节点。建议在“节点列表”中选择专用游戏节点（通常标注“Gaming”），并启用“游戏模式”（设置->游戏模式），该模式会优先处理游戏数据包。

**Q7：连接失败，显示“100%可用”但无法上网？**  
A：可能原因：1) 本地网络断开；2) DNS缓存问题。尝试：1) 检查本地网络连接；2) 在命令提示符中运行`ipconfig /flushdns`；3) 重启快连客户端。若仍无效，卸载后重新安装（注意备份设置）。
