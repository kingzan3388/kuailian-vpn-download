## 二、核心概念

### 2.1 概念定义

### 2.2 工作原理

快连加速器的核心工作流程可分为四个阶段：

1. **客户端发起连接**：用户启动快连客户端后，软件会向控制服务器发送连接请求，携带用户认证信息（账号、密码或订阅链接）。
2. **节点分配**：控制服务器根据用户的地理位置、目标访问地址和当前节点负载，通过算法分配一个最优的加速节点（如“香港-01”或“洛杉矶-02”）。该节点信息以JSON格式返回给客户端。
3. **加密隧道建立**：客户端与分配的节点服务器通过指定协议（如WireGuard）进行握手，协商加密密钥，建立端到端的加密隧道。所有用户流量（包括DNS查询、HTTP请求、UDP数据包）均通过此隧道传输。
4. **数据转发与优化**：节点服务器解密用户请求后，将其转发至目标服务器（如YouTube的CDN节点）。响应数据流经节点服务器时，会进行压缩、缓存或重新路由，最后加密回传至用户设备。

**关键优化技术**：

- **TCP BBR拥塞控制**：启用Google的BBR算法，在高丢包环境下仍能保持较高吞吐量。
- **零丢包重传机制**：对UDP流量（如游戏数据）采用FEC（前向纠错）技术，减少重传次数。
