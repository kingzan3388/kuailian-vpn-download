## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）** 是一种通过公共网络（如互联网）建立加密连接的技术。它允许用户在远程位置安全地访问内部网络资源，同时隐藏真实IP地址，保护在线活动不被第三方窥探。

**快连VPN** 是一款专注于提供高速、稳定且安全连接的VPN服务。其核心特点包括：
- **无日志政策**：声称不记录用户的任何在线活动或连接日志。
- **多协议支持**：支持WireGuard、OpenVPN、IKEv2等多种主流VPN协议，以平衡速度与安全性。
- **全球节点覆盖**：在多个国家和地区部署了服务器节点，方便用户访问全球内容。
- **一键连接**：提供简洁的图形界面，降低使用门槛。

### 2.2 工作原理

快连VPN的工作原理基于客户端-服务器模型。当用户启动快连VPN客户端并连接到某个服务器节点时，会发生以下过程：

1. **身份验证与隧道建立**：客户端向服务器发送连接请求，并通过预共享密钥或证书进行身份验证。验证通过后，双方使用协商的加密协议（如WireGuard的ChaCha20加密）建立一个加密隧道。
2. **数据封装与加密**：用户设备发出的所有网络流量（包括网页浏览、文件下载、流媒体等）都会被封装在加密数据包中。这意味着即使数据包在传输过程中被截获，攻击者也无法读取其内容。
3. **IP地址替换**：原始数据包中的源IP地址（用户真实IP）被替换为VPN服务器的IP地址。这样，目标网站或服务只能看到VPN服务器的IP，从而隐藏了用户的真实位置和身份。
4. **数据转发与解密**：加密数据包通过互联网传输到快连VPN服务器。服务器解密数据包后，将其转发到目标网站或服务。返回的数据流则经历相反的过程：服务器加密数据，客户端解密并呈现给用户。

**关键协议对比**：
- **WireGuard**：现代、高效，使用ChaCha20加密，延迟低，适合移动设备和高速连接。
- **OpenVPN**：成熟、高度可配置，使用AES-256加密，兼容性极佳，但配置相对复杂。
- **IKEv2**：对移动网络切换（如从Wi-Fi切换到蜂窝网络）非常稳定，常用于iOS设备。

快连VPN通常会根据用户网络环境自动选择最优协议，或在设置中允许用户手动切换。这种机制确保了在保证安全性的前提下，最大化连接速度和稳定性。
