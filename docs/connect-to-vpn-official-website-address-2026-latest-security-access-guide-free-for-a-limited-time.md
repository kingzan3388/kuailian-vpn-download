## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）** 是一种通过公共网络（如互联网）建立加密隧道，实现远程安全访问私有网络的技术。简单来说，它会在您的设备与远程服务器之间创建一个加密的“专用通道”，使得您的所有网络流量都经过这个通道传输。

**快连VPN** 在此基础上进行了深度优化。它不仅是一个标准的VPN服务，更是一个集成了智能分流、协议混淆和全球CDN加速的综合网络解决方案。其核心目标是在保障安全性的同时，最大化网络速度和稳定性，尤其适合需要访问境外网站、观看流媒体或进行在线游戏的用户。

**关键术语解释：**
- **加密隧道**：指数据在传输前被加密，只有目标服务器能解密，防止中间人窃听。
- **协议混淆**：一种技术，将VPN流量伪装成普通的HTTPS流量，以绕过深度包检测（DPI）等网络审查机制。
- **智能分流**：又称“分应用代理”，允许用户指定哪些应用或网站走VPN，哪些走本地网络，避免所有流量都经过VPN导致速度下降。

### 2.2 工作原理

快连VPN的工作原理可以拆解为以下几个关键步骤：

1. **客户端发起连接请求**：当您打开快连VPN客户端并点击连接时，客户端会向快连的全球服务器网络发送一个加密的握手请求。

2. **身份验证与密钥交换**：服务器验证您的账户身份（通常通过API密钥或Token），并与客户端协商一个临时的加密密钥。这个过程通常采用**TLS 1.3**或**WireGuard**等现代协议，确保密钥交换过程本身是安全的。

3. **建立加密隧道**：一旦身份验证通过，客户端和服务器之间会建立一个加密隧道。所有后续的网络流量（如网页浏览、视频流、文件下载）都会通过这个隧道传输。快连VPN支持多种协议，包括OpenVPN、IKEv2、WireGuard以及其自主研发的**Kuaillai-Protocol**，后者在低延迟和高吞吐量方面表现尤为出色。

4. **数据封装与转发**：您的设备发出的数据包首先被快连客户端加密，然后封装在一个新的数据包中，发送到快连服务器。服务器解密后，将原始数据包转发到目标网站或服务（如Google、Netflix）。目标服务器返回的数据也会经过同样的加密和转发过程。

5. **IP地址隐藏**：从目标服务器的视角看，所有请求都来自快连服务器的IP地址，而非您的真实IP。这有效隐藏了您的地理位置和网络身份，实现了匿名访问。

6. **智能分流（可选）**：快连VPN的客户端内置了智能分流引擎。它会根据预设规则或用户自定义规则，判断哪些流量需要走VPN隧道，哪些应该直连。例如，访问国内网站时自动走本地网络以保持高速，而访问被封锁的境外网站时则通过VPN。
