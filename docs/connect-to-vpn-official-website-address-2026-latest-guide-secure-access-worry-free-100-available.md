## 二、核心概念

### 2.1 概念定义：VPN与快连VPN

**VPN（虚拟专用网络）** 是一种通过公共网络（如互联网）建立加密隧道，将用户设备与远程服务器连接的技术。它通过以下方式保护用户：

- **加密数据**：所有流量经过高强度加密，防止ISP（互联网服务提供商）、黑客或政府监控。
- **隐藏IP地址**：用户真实IP被替换为VPN服务器的IP，从而实现匿名访问。
- **绕过地理限制**：通过连接不同国家的服务器，访问仅限特定地区的网站或服务（如Netflix、YouTube等）。

### 2.2 工作原理

快连VPN的工作原理可概括为以下步骤：

1. **用户发起连接**：通过客户端（Windows、macOS、Android、iOS等）选择目标服务器（例如日本节点）。
2. **隧道建立**：客户端与服务器通过握手协议（如TLS 1.3）协商加密密钥，建立一条加密隧道。
3. **数据封装**：所有用户流量（网页浏览、视频流、文件下载等）被分割成数据包，并封装在加密层中。
4. **传输与解密**：数据包通过公网传输至快连VPN服务器，服务器解密后转发至目标网站（如Google）。
5. **返回响应**：目标网站的响应数据同样经过加密隧道返回用户设备，用户看到的是经过代理的内容。

**关键安全机制**：
- **双重加密**：部分核心节点支持AES-256位加密，配合完美前向保密（PFS），即使密钥泄露也无法解密历史流量。
- **DNS泄漏防护**：自动将DNS查询路由至VPN服务器，防止ISP窥探用户访问记录。
- **杀开关（Kill Switch）**：若VPN连接意外中断，自动切断网络访问，避免真实IP暴露。
