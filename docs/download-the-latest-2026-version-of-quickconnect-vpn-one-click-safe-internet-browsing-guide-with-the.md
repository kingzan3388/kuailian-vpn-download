4.  **数据转发与解封装**：加密后的数据包通过公共互联网传输到快连服务器。服务器收到数据包后，使用自己的私钥解密，还原出原始的请求数据。然后，服务器会用自己的IP地址作为源IP，向您真正想要访问的目标服务器（如谷歌、YouTube）发起请求。

*   **数据加密**：即使数据包在传输过程中被截获，攻击者看到的也只是乱码，无法读取原始内容。
