## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）** 是一种在公共网络（如互联网）上建立加密通道的技术。它通过在用户的设备（客户端）和远程VPN服务器之间创建一个安全的“隧道”，使得所有进出设备的数据包都经过加密处理。对于外部网络而言，用户的数据流如同“凭空消失”一般，无法被窥探或篡改。

**LetsVPN** 则是一个基于现代加密协议（如WireGuard、OpenVPN）构建的商业VPN服务。它集成了数千台分布于全球各地的服务器节点，用户通过LetsVPN客户端即可一键连接至任意节点，从而获得该节点的IP地址，实现网络身份的隐藏与地理位置的伪装。其核心价值体现在：

- **数据加密**：使用AES-256-GCM等军用级加密算法，确保数据传输的机密性。
- **IP隐藏**：替换用户的真实IP地址，防止网站追踪和广告商定位。
- **突破封锁**：绕过网络审查和地理限制，访问全球开放互联网。

### 2.2 工作原理

LetsVPN的工作原理可以分解为以下几个关键步骤：

1. **客户端初始化**：用户在设备上安装LetsVPN客户端后，客户端会与LetsVPN的认证服务器建立连接，验证用户的订阅状态和身份凭证（如账户密码或一次性密钥）。

2. **隧道建立**：认证通过后，客户端根据用户选择的服务器节点（如美国、日本、新加坡等），与目标VPN服务器协商加密参数。LetsVPN支持多种协议：
   - **WireGuard**：新一代轻量级协议，代码量少、性能极高，适合移动设备和低功耗场景。
   - **OpenVPN**：经典协议，兼容性广，支持TCP/UDP端口混淆，适合穿越严格防火墙。
   - **IKEv2/IPsec**：移动端优化协议，支持网络切换无缝重连。

   双方通过Diffie-Hellman密钥交换算法生成共享会话密钥，随后使用该密钥对后续通信进行对称加密。

3. **数据封装与传输**：当用户访问互联网（如浏览网页、观看视频）时，客户端会：
   - 将原始数据包（如HTTP请求）分割成小块。
   - 在每个数据块前添加VPN头部（包含新的源IP地址——即VPN服务器的IP）。
   - 使用加密算法对整个数据块（包括原始内容和新头部）进行加密。
   - 通过公共互联网将加密后的数据包发送至VPN服务器。

4. **服务器解包与转发**：VPN服务器接收到加密数据后，使用共享密钥解密，还原出原始数据包，然后根据目标地址（如Google的服务器）将其转发至公网。同时，服务器会记录返回的数据，再次加密后回传给客户端。

5. **客户端解密与呈现**：客户端收到加密的回复数据后，解密并呈现给用户。整个过程中，用户的ISP和中间路由器只能看到加密的乱码流，无法得知用户访问的具体网站或内容。

这种“加密-传输-解密”的闭环机制，确保了即便在不可信的网络环境（如公共Wi-Fi）下，用户的通信内容也绝对安全。

### 3.3 高级技巧

- **分应用路由（Split Tunneling）**：
  某些情况下，您可能希望部分应用走VPN（如浏览器），而其他应用（如本地游戏、打印服务）使用直连，以避免速度下降。在LetsVPN设置中，找到“分应用路由”或“高级路由”选项：
  - 启用功能后，添加需要走VPN的应用（如Chrome.exe、Spotify.exe）。
  - 或者，选择“仅让指定应用走VPN”，其他所有流量直连。
  ```bash
  # 示例：在Windows上通过命令行添加排除规则（假设客户端支持命令行接口）
  letsvpn-cli split-tunnel add --app "C:\Program Files\Google\Chrome\Application\chrome.exe"
  ```

- **自定义DNS服务器**：
  为防止DNS泄露，LetsVPN默认使用其自带的防污染DNS。但您可以手动设置更安全的DNS（如Cloudflare的1.1.1.1或Google的8.8.8.8）：
  1. 进入设置 -> 网络 -> DNS设置。
  2. 选择“自定义DNS”。
  3. 输入首选DNS和备用DNS地址。
  4. 保存后重新连接。

- **端口转发（Port Forwarding）**：
  如果您需要从外部访问您的设备（如运行BT下载或搭建个人网站），某些LetsVPN节点支持端口转发。请注意，此功能需要订阅高级套餐，且仅适用于部分节点。
  1. 在客户端设置中，找到“端口转发”选项。
  2. 输入您希望转发的本地端口（如8080）和远程端口（如随机分配的一个端口）。
  3. 应用设置后，外部用户可通过`VPN服务器IP:远程端口`访问您的服务。

- **连接故障自动切换**：
  开启“自动重连”或“故障转移”功能后，当当前节点不可用或速度下降时，客户端会自动尝试连接列表中的下一个最佳节点。您可以在设置中配置节点优先级列表。
