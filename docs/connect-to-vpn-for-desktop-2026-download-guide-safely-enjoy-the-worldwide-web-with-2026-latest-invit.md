## 二、核心概念

### 2.1 概念定义

在深入指南之前，有必要澄清几个核心概念，以帮助您更好地理解快连VPN的价值。

- **VPN（虚拟专用网络）**：一种通过公共网络（如互联网）建立加密隧道，将用户的设备安全地连接到远程服务器或私有网络的技术。它本质上创建了一个临时的、安全的“隧道”，使得数据在传输过程中无法被第三方窃听或篡改。
- **IP地址与地理定位**：每个联网设备都有一个唯一的IP地址，它大致指示了设备的地理位置。当您访问网站时，服务器会根据您的IP地址判断您所在的国家或地区，从而决定是否提供特定内容。VPN通过将您的流量路由到位于其他国家的服务器，使您“假装”身处该地，从而绕过地理封锁。
- **加密与协议**：VPN使用各种加密算法（如AES-256）来保护您的数据。加密协议（如OpenVPN、WireGuard）则定义了数据如何被封装和传输。快连VPN支持多种现代协议，以平衡速度与安全性。
- **邀请码**：一种用于激活或试用服务的代码，通常用于新用户注册。在快连VPN中，邀请码可提供免费体验时长或特殊优惠。

### 2.2 工作原理

理解快连VPN电脑版的工作原理，有助于您充分发挥其效能。其核心流程可概括为以下几步：

1. **客户端启动与连接**：您在电脑上启动快连VPN客户端，选择一个目标服务器节点（例如，美国、日本、新加坡）。客户端会向快连的服务器发起连接请求。

3. **建立加密隧道**：一旦密钥协商完成，客户端会在您的电脑和远程服务器之间建立一个加密隧道。这个隧道使用强加密协议（如WireGuard，因其高性能和低延迟而被广泛采用）来封装您的所有网络流量。
4. **数据封装与传输**：您的所有网络请求（例如，访问一个被封锁的网站）都会被封装在这个加密隧道中。数据包被加密、添加额外的头部信息，然后通过公共互联网发送到快连的服务器。
5. **服务器解密与转发**：快连的服务器接收到加密数据包后，使用协商好的密钥进行解密。然后，服务器以它自己的IP地址（而非您的真实IP）向目标网站发起请求。目标网站看到的是快连服务器的IP，从而认为您位于服务器所在的国家。
6. **响应返回**：目标网站的响应数据被发送回快连服务器。服务器再次加密这些数据，通过隧道传回您的电脑。客户端解密后，您就能正常访问该网站。

整个过程对用户透明，您只需点击“连接”按钮，后台便自动完成所有复杂操作。这种机制不仅隐藏了您的真实IP，还通过加密防止了ISP（互联网服务提供商）、黑客或政府机构监控您的在线活动。

  - **OpenVPN (UDP)**：速度较快，适合游戏和视频通话。
  - **OpenVPN (TCP)**：最稳定，适合在防火墙严格或网络不稳定的环境（如公司网络、公共Wi-Fi）。
- **操作步骤**：在“设置” -> “协议”中手动切换。如果遇到连接失败，尝试切换到OpenVPN TCP模式。
