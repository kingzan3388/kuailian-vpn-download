### 2.2 工作原理

快连加速器的工作流程可以抽象为以下四个关键步骤，我们通过一个简化的技术流程图来理解：

1.  **连接建立与认证**：用户启动客户端，输入账号信息（或使用邀请码激活）。客户端向控制服务器发送认证请求，控制服务器验证身份后，返回一个可用的加速节点列表（包括IP地址、端口、负载情况、加密协议等）。
2.  **隧道封装与加密**：客户端根据策略选择最优节点（通常基于延迟和丢包率）。随后，客户端使用强加密算法（如AES-256-GCM）将用户设备的原始数据包进行加密。加密后的数据包被封装在一个新的数据包中，这个新数据包的目标地址是选定的加速节点。
3.  **智能路由与传输**：加密后的数据包通过公共互联网发送到加速节点。在此过程中，快连加速器采用专有的**多路径传输协议（MPTCP变体）** 和**拥塞控制算法（如BBR）**，能够动态选择延迟最低、丢包最少的网络路径，有效规避网络拥塞和中间节点干扰。
4.  **解封装与转发**：加速节点接收到加密数据包后，使用预共享的密钥进行解密，还原出原始的数据包。然后，节点作为代理，将原始数据包发送到用户真正想要访问的目标服务器（例如一个被封锁的海外网站）。目标服务器的响应数据则沿相反路径返回。

这一机制使得互联网服务提供商（ISP）和网络中间设备只能看到用户与加速节点之间的加密流量，无法得知用户最终访问的目标，从而实现了**网络加速**（通过优质线路）和**隐私保护**（通过加密和伪装）的双重目标。
