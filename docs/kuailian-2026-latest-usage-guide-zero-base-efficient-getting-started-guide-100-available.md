## 二、核心概念

### 2.1 概念定义

**kuailian** 本质上是一个基于P2P（点对点）技术的分布式文件同步与协作网络。与传统的中心化云存储不同（如Google Drive或Dropbox），kuailian 不依赖单一服务器存储所有数据，而是通过用户设备之间直接建立安全通道进行文件传输。这种架构带来了几个关键优势：

- **去中心化**：数据不集中存储于第三方服务器，降低了单点故障和数据泄露风险。
- **高速传输**：利用设备间的直接连接（局域网或互联网），绕过了云服务器的带宽瓶颈，尤其在局域网内可实现接近线速的传输。
- **零配置**：用户无需手动设置端口转发或复杂网络配置，kuailian 自动通过NAT穿透技术（如UDP打洞）建立连接。

在2026版本中，kuailian 引入了“智能路由”概念。当直接P2P连接因网络环境（如对称NAT或防火墙）受阻时，系统会自动切换至中继节点（Relay Server），但中继节点仅作为数据转发通道，不存储文件内容，且传输过程全程加密。此外，kuailian 还支持“离线同步”模式，允许用户在无网络环境下创建本地同步目录，待网络恢复后自动合并变更。

### 2.2 工作原理

kuailian 的工作流程可概括为四个阶段：**身份注册**、**设备配对**、**连接建立**与**文件同步**。

1. **身份注册**：每个用户首次安装 kuailian 客户端时，系统会生成一对唯一的公钥/私钥（基于RSA-4096或Ed25519算法）。公钥作为用户的公开标识（类似于ID），私钥则存储在本地设备，用于签名和加密。这一步确保了用户身份的不可伪造性。

2. **设备配对**：用户通过扫描二维码、输入配对码或手动添加对方公钥，将多个设备绑定至同一账户。配对完成后，设备间会交换公钥，并建立信任关系。2026版本新增了“群组配对”功能，支持一次性将多台设备加入同一同步组。

3. **连接建立**：当设备A需要向设备B同步文件时，kuailian 客户端首先查询本地或远程的“连接数据库”（由分布式哈希表DHT维护），获取设备B的当前网络地址（IP和端口）。随后，设备A尝试通过UDP打洞技术建立直接连接。若失败，则自动切换至中继节点。整个连接过程在后台自动完成，用户无感知。

4. **文件同步**：连接建立后，文件传输采用增量同步机制。kuailian 会为每个文件生成哈希指纹（SHA-256），仅传输变更的块（Chunk），而非整个文件。例如，一个1GB的视频文件，若仅修改了片头元数据，kuyalian 只会传输修改后的块（通常仅几KB），极大节省了带宽和时间。2026版本进一步优化了“冲突解决”算法，当多设备同时修改同一文件时，系统会基于时间戳和用户优先级自动合并，或保留冲突副本供用户手动处理。

## 三、使用指南

### 3.1 安装配置

kuailian 支持主流操作系统，包括Windows、macOS、Linux、iOS和Android。以下是Windows平台的安装步骤，其他平台类似。

1. **下载客户端**：访问 [kuailian官网](https://www.kuailiansj.com)，点击“下载”按钮，选择对应操作系统的安装包（例如 `kuailian-setup-2026.1.0.exe`）。
2. **运行安装程序**：双击下载的安装包，根据提示完成安装。建议选择“自定义安装”，将安装路径设置为非系统盘（如 `D:\kuailian`），以避免占用C盘空间。
3. **启动并注册**：安装完成后，启动 kuailian。首次运行会弹出注册界面。您可以选择“创建新账户”或“登录已有账户”。创建账户时，系统会生成一个12位助记词（类似区块链钱包），请务必抄写并妥善保管，这是恢复账户的唯一凭证。
4. **设备命名**：注册成功后，系统会要求为当前设备命名（如“办公笔记本”或“家用台式机”）。命名有助于在多设备间识别。
5. **初始化同步目录**：默认情况下，kuailian 会在用户目录下创建 `kuailian_sync` 文件夹。您也可以手动添加其他目录。建议将常用工作文件夹（如 `D:\Projects`）添加为同步目录。

**配置建议**：
- 在“设置”中开启“开机自启”功能，确保同步服务持续运行。
- 对于企业用户，建议在“网络设置”中启用“中继节点”选项，以增强网络穿透成功率。
- 首次同步前，建议在“高级设置”中调整“并发传输线程数”，根据CPU核心数设置为4-8，以平衡性能与功耗。

### 3.2 基本用法

以下步骤将指导您完成一次完整的文件同步操作。

**步骤1：添加同步目录**
1. 打开 kuailian 主界面，点击左侧菜单栏的“同步目录”。
2. 点击“添加目录”按钮，选择您希望同步的文件夹（例如 `D:\Work\Report`）。
3. 在弹出的对话框中，选择同步模式（“双向同步”为默认，表示任一设备修改后都会同步；也可选择“仅上传”或“仅下载”）。

**步骤2：配对设备**
1. 在“设备管理”页面，点击“添加设备”。
2. 您可以选择“扫码添加”或“输入配对码”。若使用扫码，让另一台设备（如手机）打开 kuailian，点击“我的设备”中的二维码图标，扫描即可。
3. 配对成功后，两台设备会出现在设备列表中，并显示连接状态（“在线”或“离线”）。

**步骤3：同步文件**
1. 在已配对的设备A（如笔记本）上，将文件放入 `D:\Work\Report` 目录（例如 `2026_Plan.docx`）。
2. 观察 kuailian 界面，文件状态会显示为“正在同步...”，并显示传输进度和速度。通常几秒内即可完成。
3. 在设备B（如台式机）上，打开 `kuailian_sync\Work\Report` 目录，您会看到 `2026_Plan.docx` 已自动出现。文件内容完全一致。

**步骤4：查看同步历史**
- 点击主界面的“历史记录”选项卡，可查看所有文件的同步事件（创建、修改、删除），包括时间戳和操作设备。

### 3.3 高级技巧

**技巧1：选择性同步**
kuailian 支持“忽略规则”，允许您排除特定文件或目录。例如，在同步代码项目时，您可能不想同步 `node_modules` 或 `.git` 文件夹。操作如下：
1. 进入“同步目录”设置，点击对应目录的“高级规则”。
2. 添加忽略模式，例如输入 `*.exe` 或 `node_modules/`。
3. 保存后，这些文件将不会被同步，节省了时间和空间。

**技巧2：版本控制与回滚**
kuailian 内置了文件版本历史功能，默认保留最近30天的变更记录。要恢复旧版本：
1. 右键点击文件，选择“查看版本历史”。
2. 在弹出窗口中，您会看到所有历史版本，包括修改时间与设备。
3. 选择目标版本，点击“恢复”，系统会自动替换当前文件。

**技巧3：命令行操作**
对于高级用户，kuailian 提供了CLI（命令行接口），可用于脚本自动化。例如，使用批处理文件批量添加同步目录：
```bash
kuailian-cli add-sync --path "D:\Data\ProjectA" --mode bidirectional
kuailian-cli add-sync --path "D:\Data\ProjectB" --mode upload-only
kuailian-cli start-sync
```
该功能在2026版本中得到了增强，支持通过JSON文件批量配置同步规则。

**技巧4：跨区域加速**
若您经常在跨国网络环境下使用，可在“网络设置”中手动选择“最佳中继节点”。kuailian 在全球部署了多个中继节点（如美国、欧洲、新加坡），选择离您最近的节点可显著降低延迟。此外，开启“智能QoS”功能，可优先同步重要文件（如办公文档），延迟同步大文件（如视频）。

## 四、常见问题FAQ

**Q1：kuailian 是否支持多平台？**
A：完全支持。kuailian 2026版本提供了Windows（7/10/11）、macOS（10.15+）、Linux（Ubuntu/Debian/CentOS）、iOS（12+）和Android（8+）的客户端。不同平台间的同步完全无缝，例如您可以在Windows上编辑文档，在手机上实时查看更新。

**Q2：传输速度为什么有时很慢？**
A：传输速度受多种因素影响：网络带宽、设备性能、文件大小以及连接类型（P2P vs 中继）。若速度不理想，请检查：
- 确保双方设备网络稳定，避免使用公共Wi-Fi。
- 在“网络设置”中关闭“限速上传”选项。
- 若使用中继节点，尝试切换至其他节点。
- 对于大文件，建议开启“增量同步”模式（默认开启）。

**Q3：如何确保数据安全？**
A：kuailian 采用端到端加密（E2EE），所有数据在传输前都会使用接收方的公钥进行加密，只有接收方私钥能解密。即使数据经过中继节点，也无法被第三方读取。此外，本地存储的文件默认使用AES-256加密（可选），防止设备丢失后数据泄露。建议启用“双因素认证”以增强账户安全。

**Q4：免费版和付费版有什么区别？**
A：kuailian 提供基础免费版，支持最多5台设备、单个文件最大2GB、同步目录数量不限。付费版（Pro版，每月$9.99）则支持无限设备、单个文件最大50GB、优先中继节点、文件版本保留90天以及专属客服支持。对于个人用户，免费版通常足够；团队或企业用户建议升级Pro版。

**Q5：我忘记了助记词，如何恢复账户？**
A：助记词是恢复账户的唯一凭证，无法通过其他方式找回。若丢失，您将无法访问原有设备列表和同步数据。强烈建议在创建账户后，立即将助记词备份到安全位置（如离线密码管理器或纸质记录）。若仍无法找回，您只能创建新账户并重新配对设备。

**Q6：如何卸载 kuailian？**
A：在Windows中，通过“控制面板”->“程序和功能”找到kuailian并卸载。但请注意，卸载不会删除本地同步目录中的文件。若需彻底清理，建议在卸载前手动删除 `%AppData%\kuailian` 和 `%LocalAppData%\kuailian` 文件夹。macOS用户将应用拖入废纸篓即可。
