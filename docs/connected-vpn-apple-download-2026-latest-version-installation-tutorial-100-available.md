## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）**：一种通过公共网络（如互联网）建立加密隧道，使远程设备能够安全地访问私有网络或隐藏真实IP地址的技术。简单来说，VPN将您的网络流量进行加密后，通过远程服务器转发，从而隐藏您的真实位置与行为。

**快连VPN**：一款基于现代加密协议（如WireGuard、IKEv2）的VPN服务，其核心优势在于：
- **低延迟**：通过智能路由算法自动选择最优节点。
- **高吞吐量**：支持UDP与TCP协议优化，适合流媒体与游戏场景。
- **零日志政策**：不记录用户连接日志，保护隐私。
- **跨平台支持**：覆盖iOS、macOS、Android、Windows等主流系统。

**苹果生态适配**：针对iOS 17+与macOS Sonoma+的系统特性（如网络扩展框架NEVPNManager）进行了原生集成，确保在后台运行时不影响系统稳定性。

### 2.2 工作原理

快连VPN的运作遵循以下核心流程（以苹果设备为例）：

1. **客户端初始化**：用户启动快连APP后，应用通过系统API（NetworkExtension）请求创建虚拟网络接口。
2. **加密握手**：客户端与服务器端通过TLS 1.3或WireGuard的Noise协议进行身份验证，协商对称加密密钥（如AES-256-GCM）。
3. **隧道建立**：认证通过后，系统在设备上创建一个虚拟的“网络适配器”，所有应用程序的网络流量（包括DNS查询）均被重定向至此适配器。
4. **数据封装与传输**：
   - 原始数据包（如HTTP请求）被分割为更小的数据块。
   - 每个数据块被加密并添加新的IP头部（伪装为服务器IP）。
   - 通过UDP或TCP协议发送至服务器，服务器解密后转发至目标网站。
5. **响应回传**：目标网站返回的数据同样经过加密隧道回传至客户端，系统自动解密后交付给对应应用。

**关键协议对比**：
- **WireGuard**：快连默认协议，基于现代密码学（Curve25519、ChaCha20），代码量小（约4000行），延迟极低，适合移动设备。
- **OpenVPN**：传统协议，兼容性强但配置复杂，快连作为备用选项提供。
- **IKEv2**：苹果原生支持，断线重连速度快，适合网络环境频繁切换的场景。

**分流机制**：快连支持“全局模式”与“分流模式”。分流模式下，仅指定流量（如境外网站）通过VPN隧道，国内流量直连，从而降低延迟并节省带宽。

**Q2：连接后网速很慢或频繁断连？**
A：可能原因及解决方案：
- **服务器负载过高**：切换至低负载节点（负载<50%）。
- **网络环境限制**：若在校园网、企业网络或部分运营商环境下，尝试切换协议至OpenVPN（TCP 443端口）。
- **设备后台限制**：关闭低数据模式或省电模式，允许VPN后台运行。
- **DNS解析问题**：在设置中启用“自定义DNS”并填入1.1.1.1或8.8.8.8。

**Q3：快连VPN是否支持苹果的“始终开启”功能？**
A：支持。在iOS设置中，进入“通用-VPN与设备管理-快连VPN”，开启“按需连接”和“始终开启”开关。注意：此功能会强制所有流量通过VPN，可能导致部分国内应用无法使用，建议配合分流模式使用。

**Q4：如何确保快连VPN不会泄露真实IP？**
A：快连采用以下机制：
- **IPv6泄漏防护**：自动禁用IPv6，防止DNS泄漏（可在设置中验证）。
- **Kill Switch**：当VPN意外断开时，自动切断所有网络连接（需在设置中开启）。
- **WebRTC泄漏防护**：应用内置WebRTC拦截功能，防止浏览器泄漏真实IP。
- 建议定期访问 [ipleak.net](https://ipleak.net) 进行泄漏测试。

**Q5：快连VPN是否支持苹果的“家庭共享”？**
A：目前不支持通过“家庭共享”分发订阅。每个账户独立使用，但可在同一账户下登录多台设备（最多5台）。若需为家人配置，建议创建子账号或使用共享订阅计划。

**Q6：更新系统后快连VPN无法使用？**
A：苹果系统更新后，VPN应用可能需要重新授权。请尝试：
1. 在设置中删除VPN配置（通用-VPN-点击快连VPN-删除配置）。
2. 重新启动快连APP，系统会提示添加新配置，按提示操作即可。
3. 若问题持续，卸载并重新安装应用（注意备份分流规则）。
