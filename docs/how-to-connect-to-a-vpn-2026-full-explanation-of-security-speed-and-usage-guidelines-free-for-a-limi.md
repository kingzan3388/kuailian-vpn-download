## 二、核心概念

### 2.1 概念定义

**VPN（Virtual Private Network，虚拟专用网络）** 是一种通过公共网络（如互联网）建立加密隧道，实现远程安全访问私有网络或隐藏真实IP地址的技术。快连VPN在此基础上，集成了多协议支持、智能路由、无日志政策等特性，旨在为用户提供“一键式”的隐私保护与全球访问体验。

快连VPN的核心价值在于：
- **隐私保护**：通过加密数据流，防止ISP（互联网服务提供商）、黑客或第三方监控您的在线活动。
- **突破限制**：绕过地理封锁（如流媒体、社交平台）和网络审查。
- **匿名性**：隐藏真实IP地址，使用虚拟IP进行通信。

### 2.2 工作原理

快连VPN的工作原理基于以下几个关键技术模块：

1. **加密隧道技术**：快连VPN使用AES-256-GCM（高级加密标准，256位密钥，伽罗瓦/计数器模式）对用户数据进行加密。这是目前业界公认的顶级加密算法，即使在量子计算时代也具有较高的安全性。数据在离开您的设备时即被加密，只有快连VPN服务器解密后才能转发到目标网站，反之亦然。

2. **多协议支持**：快连VPN支持多种VPN协议，包括：
   - **WireGuard**：新一代轻量级协议，具有极低延迟和高效能，适合移动设备和低功耗场景。
   - **OpenVPN**：经典开源协议，兼容性强，适合需要高度自定义的用户。
   - **IKEv2/IPSec**：适合移动设备，能在网络切换（如WiFi到4G）时保持连接稳定。
   - **Shadowsocks**：针对被封锁网络优化，适合严格审查环境。

3. **智能路由与分流**：快连VPN内置智能路由引擎，可根据目标IP地址或域名自动选择最优服务器节点，并支持“全局模式”和“分流模式”（如仅特定应用或网站走VPN，其他流量直连）。这避免了所有流量都经过VPN导致的带宽浪费和延迟增加。

4. **无日志政策（No-Log Policy）**：快连VPN承诺不记录用户的连接时间、访问记录、DNS查询等敏感信息。其服务器采用内存优先存储（RAM-only），重启即清除所有临时数据，从技术上保证了用户隐私。

5. **DNS泄漏防护**：内置DNS泄漏保护机制，确保所有DNS查询都通过加密隧道转发，防止ISP或第三方通过DNS请求获取您访问的网站信息。

### 3.3 高级技巧

#### 3.3.1 配置分流规则

通过“设置” -> “路由规则” -> “自定义规则”，您可以：
- **添加应用**：选择特定应用（如Chrome、Steam）走VPN，其他流量直连。
- **添加域名/IP**：指定某些网站（如github.com）强制走VPN，其他不经过。
- **排除规则**：让某些流量（如本地银行网站）绕过VPN。

**示例**：分流策略配置文件（JSON格式，部分客户端支持导入）

```json
{
  "rules": [
    {
      "type": "domain",
      "value": "*.netflix.com",
      "action": "proxy"
    },
    {
      "type": "ip",
      "value": "192.168.1.0/24",
      "action": "direct"
    }
  ]
}
```

#### 3.3.2 使用多跳（Multi-Hop）功能

快连VPN提供“双节点”模式，即流量依次经过两个不同地区的服务器，进一步增加匿名性。操作步骤：
1. 进入“高级设置” -> “多跳”或“链式代理”。
2. 选择第一个节点（如日本），再选择第二个节点（如美国）。
3. 连接后，您将拥有日本IP的入口和美国IP的出口。

**注意**：多跳会增加延迟，适合对隐私要求极高的场景（如新闻记者、金融交易）。
