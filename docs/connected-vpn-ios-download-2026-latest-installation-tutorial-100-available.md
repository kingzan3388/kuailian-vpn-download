## 二、核心概念

### 2.1 概念定义

VPN（Virtual Private Network，虚拟专用网络）是一种通过公共网络（如互联网）建立加密隧道，实现远程安全通信的技术。简单来说，当您使用VPN时，您的设备会与VPN服务器建立一条加密连接，所有网络流量都会通过这条隧道传输，从而隐藏您的真实IP地址，并模拟成服务器所在地区的网络身份。

快连VPN是专门为突破网络限制而优化的VPN服务，其核心特点包括：
- **协议支持**：采用WireGuard、OpenVPN等现代加密协议，兼顾速度与安全性。
- **节点覆盖**：在全球多个国家和地区部署节点，如美国、日本、新加坡、香港等，用户可自由切换。
- **零日志策略**：承诺不存储用户访问记录，保护隐私。
- **智能分流**：支持全局代理或按需路由，避免国内网站访问延迟。

### 2.2 工作原理

快连VPN的工作机制基于客户端-服务器模型。当用户在iOS设备上启动快连VPN客户端并选择服务器后，系统会执行以下步骤：

1. **认证与握手**：客户端向服务器发送连接请求，包含加密的认证信息。服务器验证通过后，双方协商加密算法和密钥。
2. **隧道建立**：利用WireGuard或OpenVPN协议，在用户设备和远程服务器之间创建一个虚拟网络接口。所有数据包被封装在加密隧道中，原始IP和内容对中间节点不可见。
3. **流量转发**：用户设备将网络请求（如访问Google）发送至VPN服务器，服务器解密后以自身IP向目标网站发起请求，再将响应数据加密后返回给用户设备。
4. **DNS解析**：快连VPN默认接管DNS查询，通过其自有的DNS服务器（如1.1.1.1或自定义）进行解析，防止DNS污染和劫持。

这一过程确保了用户的真实IP地址被隐藏，同时所有通信内容经过高强度加密（如ChaCha20或AES-256），即使被网络运营商或黑客拦截，也无法解读数据。对于iOS用户，快连VPN还利用了Apple的Network Extension框架，确保VPN连接在后台稳定运行，且不会影响系统整体性能。
