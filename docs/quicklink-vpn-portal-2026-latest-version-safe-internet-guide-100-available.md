## 二、核心概念

### 2.1 概念定义

**VPN（Virtual Private Network，虚拟专用网络）** 是一种在公共网络（如互联网）上建立专用加密通道的技术。它通过在用户设备与目标服务器之间创建一个“加密隧道”，将用户的所有网络流量进行封装和加密，然后再通过远程VPN服务器转发到目标网站。

对于“快连VPN”而言，其核心价值在于：**伪装真实IP地址**（用户显示的IP变为VPN服务器的IP）、**加密传输数据**（防止ISP或黑客窃听）、以及**突破地理封锁**（访问被区域限制的内容）。

要理解快连VPN为何能实现“安全上网”，我们需要拆解其工作流程：

3.  **建立加密隧道**：认证通过后，客户端与服务器之间建立一条加密的虚拟通道。所有后续的网络数据包（如HTTP请求、DNS查询）都会被加密打包。
4.  **数据封装与转发**：
    -   当您访问一个网站时，您的请求数据包被快连VPN客户端加密。
    -   这个加密后的数据包被封装在一个新的IP数据包中，目标地址是快连VPN服务器。

    -   VPN服务器解密数据包，取出原始请求，并以VPN服务器的IP地址作为源地址，向目标网站发出请求。
5.  **响应返回**：目标网站返回的数据，同样经过VPN服务器加密后，通过隧道传回您的设备，再由客户端解密呈现。
