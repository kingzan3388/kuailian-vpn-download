## 二、核心概念

### 2.1 概念定义

**VPN（Virtual Private Network，虚拟专用网络）** 是一种在公共网络（如互联网）上建立加密隧道的技术。当您使用快连VPN电脑版时，您的所有网络流量会先通过一个加密的“隧道”传输到快连VPN的服务器，然后由该服务器代为访问目标网站或服务。这一过程实现了三个核心功能：
- **加密**：将您的数据（如密码、浏览记录、聊天内容）转换为不可读的密文，防止中间人攻击。
- **匿名化**：隐藏您的真实IP地址，替换为VPN服务器的IP地址，使网站无法追踪您的物理位置。
- **突破限制**：通过选择不同国家的服务器，您可以绕过地理封锁，访问全球互联网资源。

**快连VPN** 是一款专注于Windows、macOS、iOS和Android平台的商业VPN服务。其电脑版客户端以“一键连接”、“超低延迟”和“零日志政策”著称，特别适合对网速和隐私要求较高的用户。

### 2.2 工作原理

快连VPN电脑版的工作原理可以分解为以下五个关键步骤：

1. **客户端启动与认证**：用户启动快连VPN客户端，输入账号密码（或通过令牌登录）。客户端与快连的认证服务器建立SSL/TLS加密连接，验证用户身份。
2. **选择服务器与协议**：用户从服务器列表中选择一个国家或地区的节点（如“日本-高速1”）。客户端会根据所选节点，自动选择最优的VPN协议（如WireGuard、OpenVPN或IKEv2）。其中，**WireGuard** 是目前快连VPN默认推荐的协议，因其内核级优化，具备极低的延迟和更高的吞吐量。
3. **建立加密隧道**：客户端与远端VPN服务器通过UDP或TCP端口（如443端口）建立加密隧道。快连VPN使用AES-256-GCM加密算法，这是目前军方和政府机构使用的标准，理论上无法被暴力破解。
4. **数据封装与转发**：您的所有网络数据包（如HTTP请求、DNS查询）在本地被加密后，封装进新的IP数据包中。这些数据包通过互联网发送到快连VPN服务器。服务器解密后，以自身IP地址为源地址，向目标网站发起请求。
5. **响应返回与解密**：目标网站返回的数据（如网页内容、视频流）到达快连VPN服务器后，再次被加密，原路返回至您的电脑。客户端解密后，您才能看到正常的网页或视频。

**关键机制**：快连VPN内置了 **Kill Switch（网络断开开关）** 功能。一旦VPN连接意外中断，Kill Switch会立即切断您的所有网络访问，防止真实IP地址泄露。此外，**DNS泄漏保护** 确保所有DNS查询都通过VPN隧道进行，避免被ISP劫持。

**Q2: 连接快连VPN后，网速变得很慢怎么办？**

2. **更换协议**：在设置中将协议从WireGuard切换为OpenVPN (UDP)，后者在某些网络下更稳定。
3. **关闭其他应用**：检查是否有其他程序（如BT下载、视频会议）占用带宽。
4. **测试本地网络**：断开VPN后测速，如果本地网速本身较慢（如<20Mbps），请升级您的宽带套餐。
