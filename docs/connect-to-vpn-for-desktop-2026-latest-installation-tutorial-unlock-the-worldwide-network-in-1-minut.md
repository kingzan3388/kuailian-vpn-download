## 二、核心概念

### 2.1 概念定义

- **VPN（Virtual Private Network）**：在公共网络上建立一条逻辑上的加密通道，使客户端与服务器之间传输的数据如同在私有网络中一样安全。
- **隧道协议**：决定数据如何封装和传输的规则。常见协议包括：
  - **OpenVPN**：开源、高安全性，但速度较慢。
  - **WireGuard**：新一代协议，代码量少、速度快、延迟低（快连VPN默认采用此协议）。
  - **IKEv2/IPsec**：移动设备友好，支持断线重连。
- **节点**：分布在全球各地的物理或虚拟服务器，用户通过连接节点获得该地区的IP地址。

### 2.2 工作原理

快连VPN电脑版的工作流程遵循以下逻辑：

1. **客户端启动**：用户点击“连接”后，快连客户端向服务器请求分配最优节点。
2. **握手与密钥交换**：客户端与节点使用WireGuard协议进行公钥交换，生成临时会话密钥。
3. **隧道建立**：所有本地流量（或指定应用流量）被封装在加密数据包中，通过UDP（默认）或TCP隧道发送至节点。
4. **数据转发**：节点解密数据包，并以节点自身的IP地址向目标网站发起请求，获取响应后加密返回客户端。
5. **智能路由**：快连2026版新增AI节点选择算法，根据用户地理位置、网络延迟、丢包率实时切换节点，确保低延迟。

> **关键点**：整个过程对用户透明，浏览器或应用看到的只是来自快连节点的IP地址。
