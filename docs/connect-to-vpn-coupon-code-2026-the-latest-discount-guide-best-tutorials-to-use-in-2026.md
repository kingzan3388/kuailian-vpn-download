### 2.2 工作原理

理解快连VPN的工作原理，有助于您更好地配置和使用它。其核心流程如下：

1. **隧道封装**：当您在设备上启动快连VPN客户端并选择一个节点（如美国、日本）后，客户端会与快连的服务器建立一条加密的隧道。这类似于在公共互联网中挖了一条“专属管道”。
2. **数据加密**：在数据离开您的设备前，快连VPN会使用高级加密标准（AES-256-GCM）等强加密算法对您的所有网络数据包进行加密。即使这些数据在传输过程中被截获，攻击者也无法解析其内容。
3. **地址隐藏**：您的真实IP地址被替换为快连VPN服务器的IP地址。目标网站只能看到该服务器的地址，从而无法追踪您的物理位置。
4. **流量转发**：加密后的数据包通过隧道传输到快连服务器，服务器对其进行解密，然后代表您向目标网站发起请求。网站返回的数据再按相反路径——加密、传输、解密——送回您的设备。
