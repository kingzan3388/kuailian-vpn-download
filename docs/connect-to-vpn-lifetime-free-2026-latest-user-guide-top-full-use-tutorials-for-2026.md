## 二、核心概念

### 2.1 概念定义

在深入使用指南之前，有必要先厘清几个核心术语，以便更好地理解快连VPN的工作机制。

*   **VPN (Virtual Private Network，虚拟专用网络)**：本质上，VPN是在公共互联网（如你的家庭宽带或移动4G/5G网络）上建立的一条加密的、专用的“隧道”。你的所有网络流量都会通过这条隧道传输，在数据离开你的设备之前就被加密，然后由VPN服务器进行解密后发送到目标网站。这样，你的真实IP地址被隐藏，取而代之的是VPN服务器的IP地址，从而实现匿名访问和突破地理限制。
*   **加密协议 (Encryption Protocol)**：这是VPN的“语言”和“锁”。它定义了数据如何被打包、加密和传输。常见的协议包括OpenVPN（开源、高度安全）、WireGuard（新一代协议，速度快、代码精简）、IKEv2（移动设备友好）等。快连VPN通常会根据用户网络环境自动选择最优协议，或提供手动切换选项。
*   **服务器节点 (Server Node)**：指分布在全球各地的物理或虚拟服务器。当你连接快连VPN时，实际上是连接到了其中一个节点。节点越多、分布越广，你能访问的区域就越多，也越容易找到低延迟的节点。
*   **DNS泄漏 (DNS Leak)**：当你使用VPN时，DNS请求（将域名如`google.com`转换为IP地址）本应通过VPN隧道发送，以确保你的所有请求都匿名。如果DNS请求绕过了VPN隧道，直接发送给你的ISP（互联网服务提供商），就发生了DNS泄漏，你的真实位置和访问记录可能被暴露。快连VPN内置了防泄漏机制，确保DNS请求始终安全。

掌握以下高级技巧，可以让你更好地利用快连VPN，获得更优体验。

*   **重要性**：防止因VPN意外断开导致真实IP暴露。

*   **场景**：你只想让特定应用（如浏览器、Twitter）走VPN流量，而其他应用（如银行、外卖软件）使用本地网络，以避免被检测或提高速度。
*   **操作**：在Android客户端的“设置”中，找到“分应用代理”或“应用过滤”功能。开启此功能后，会列出手机所有应用。勾选需要走VPN的应用，其他应用则自动绕过VPN。

**4. 自定义DNS**

*   **场景**：某些网站因DNS污染无法访问，或你想使用更快的公共DNS。
*   **操作**：在“设置”中找到“DNS”选项。默认是“自动”。你可以手动设置为 `1.1.1.1` (Cloudflare) 或 `8.8.8.8` (Google) 等公共DNS，以获得更快的解析速度和更好的隐私保护。
