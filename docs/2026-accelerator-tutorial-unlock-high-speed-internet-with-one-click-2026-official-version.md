## 二、核心概念

### 2.1 概念定义

**快连加速器**是一种基于软件定义网络（SDN, Software-Defined Networking）和虚拟专用网络（VPN, Virtual Private Network）技术优化而成的网络加速工具。它的核心目标是**优化网络路径**和**降低传输延迟**，而不是简单地隐藏IP地址。与传统的VPN不同，快连加速器更侧重于以下三个方面：

- **智能路由优化**：实时分析全球数千个节点的网络状态，自动为用户选择当前延迟最低、丢包率最少的最佳传输路径。
- **协议栈优化**：针对不同的应用场景（如游戏、视频、网页浏览），自适应调整TCP/UDP协议参数，减少数据包重传。
- **多路复用与负载均衡**：将用户的数据流量分散到多条加密通道中，避免单一节点过载，从而保证整体连接的稳定性和速度。

### 2.2 工作原理

快连加速器的工作机制可以概括为“感知-决策-执行”三个步骤：

1.  **感知阶段（网络探测）**：当用户启动快连加速器并尝试访问目标服务器（例如，一个位于美国的游戏服务器）时，客户端首先会向快连加速器的中央调度服务器发送请求。调度服务器会立即启动一个“网络探测”任务，向用户所在节点和目标服务器之间的所有可用中继节点发送探测数据包，实时测量这些链路的**往返时间（RTT, Round-Trip Time）**、**丢包率（Packet Loss）** 和**可用带宽（Bandwidth）**。

2.  **决策阶段（路径选择）**：调度服务器将收集到的海量网络数据输入到一个基于机器学习（ML, Machine Learning）的智能算法模型中。该模型会根据用户当前的应用类型（例如，游戏对延迟敏感，流媒体对带宽敏感）和实时网络状况，计算出最优的传输路径。例如，对于《英雄联盟》这类游戏，算法可能会优先选择RTT小于30ms的节点；对于Netflix的4K视频，则会优先选择带宽大于50Mbps且丢包率低于0.1%的节点。

3.  **执行阶段（隧道建立）**：一旦路径确定，快连加速器客户端会立即与选定的中继节点建立一条**加密的隧道**。这条隧道通常使用先进的**WireGuard**或**AES-256-GCM**加密协议，确保数据在传输过程中不被窃听或篡改。之后，用户的所有网络请求都会通过这条优化后的加密隧道发送到目标服务器，从而实现“一键加速”的效果。

    - **分应用模式**：只加速指定的应用程序（如游戏、浏览器）。这是最推荐的模式，可以节省流量并避免影响本地网络服务。

### 3.3 高级技巧

对于希望进一步优化体验或解决特定问题的用户，以下是一些高级技巧：

**1. 自定义路由规则（Split Tunneling）**

- **场景**：你希望加速《绝地求生》游戏，但同时需要访问公司内网（公司内网不支持VPN）。
- **操作**：进入“设置” -> “分应用模式”。在“加速应用”列表中，添加 `steam.exe` 和 `TslGame.exe`。同时，在“绕过规则”中，添加你公司内网的IP地址段，例如 `192.168.1.0/24`。这样，只有游戏流量会走加速通道，公司内网流量直连。

**2. 手动设置DNS**

- **场景**：某些网站（如Netflix）会通过DNS劫持来检测加速器流量，导致无法解锁。
- **操作**：在“设置” -> “网络”中，关闭“自动DNS”，并手动输入以下公共DNS服务器：
    ```text
    首选DNS: 8.8.8.8 (Google DNS)
    备用DNS: 1.1.1.1 (Cloudflare DNS)
    ```
    这可以防止DNS泄露，并提高内容解锁成功率。

**3. 命令行高级参数（适用于高级用户）**

- **场景**：你希望在电脑开机后自动以最小化模式启动快连加速器，并自动连接到指定节点。
- **操作**：创建快连加速器的快捷方式，右键点击“属性”，在“目标”栏的末尾添加以下参数：
    ```bash
    "C:\Program Files\QuickConnect\QuickConnect.exe" --minimize --connect --node "US-NewYork-01"
    ```
    - `--minimize`：启动后最小化到系统托盘。
    - `--connect`：自动连接。
    - `--node "节点ID"`：指定连接节点。节点ID可以在节点列表的属性中查看。

## 四、常见问题FAQ

**Q1: 为什么我连接后网速反而变慢了？**

**A:** 这通常是由以下几个原因造成的：
1.  **选择了错误的节点**：距离你太远的节点或负载过高的节点会导致延迟增加。请尝试切换到“延迟最低”或“智能模式”。
2.  **协议不匹配**：某些网络环境（如校园网、公司防火墙）会限制UDP协议。请在“设置”中尝试将协议切换为“OpenVPN (TCP)”或“IPSec”。
3.  **本地网络问题**：请检查你本地路由器是否开启了QoS（服务质量）设置，或者后台是否有其他程序（如迅雷）在大量占用带宽。建议关闭其他占用带宽的程序。
4.  **服务器限速**：请检查你的套餐是否已用完流量或已达到带宽上限。可以登录官方网站 [https://www.kuailiansj.com](https://www.kuailiansj.com) 查看账户状态。

**Q2: 快连加速器支持哪些设备？可以同时连接几台设备？**

**A:** 快连加速器支持Windows、macOS、iOS、Android和部分Linux系统。根据你的套餐不同，允许同时连接的设备数量也不同。免费试用账户通常只允许1台设备在线，付费套餐（如“家庭版”）通常支持3-5台设备同时在线。你可以在“我的账户”页面管理已连接的设备。

**Q3: 连接后，我无法访问某些国内网站（如银行、淘宝）怎么办？**

**A:** 这通常是因为开启了“全局模式”导致的。请尝试以下操作：
1.  切换到“分应用模式”，只加速你需要的海外应用。
2.  在“设置” -> “分应用模式”中，添加“绕过规则”，将国内网站的域名或IP地址段加入白名单。
3.  如果问题依旧，可以暂时断开加速器，访问国内网站后再重新连接。

**Q4: 为什么游戏中的延迟（Ping值）显示很高，但实际感觉不卡？**

**A:** 这是一个常见现象。游戏内显示的Ping值通常是ICMP协议的响应时间，而快连加速器实际使用的是UDP或TCP协议的优化通道。有时游戏Ping值显示高，但实际数据包经过加速器优化后，丢包率和抖动（Jitter）大幅降低，因此游戏体验反而更流畅。建议以实际游戏体验为准，而不是过分关注Ping数值。你可以在快连加速器客户端内查看“加速延迟”，这个数值更接近真实传输延迟。

**Q5: 如何卸载快连加速器？**

**A:** 标准的卸载方法：
1.  关闭快连加速器客户端。
2.  打开Windows的“设置” -> “应用” -> “应用和功能”。
3.  在列表中找到“快连加速器”，点击“卸载”。
4.  为了彻底清理残留文件，建议卸载后使用系统自带的“磁盘清理”工具，或手动删除 `C:\ProgramData\QuickConnect` 和 `%AppData%\QuickConnect` 文件夹（如有）。

**Q6: 我的账户被盗用了，该怎么办？**
