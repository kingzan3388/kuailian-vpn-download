### 3.3 高级技巧

**技巧一：配置分流规则（路由规则）**

为了避免所有流量都经过代理导致访问国内网站变慢，快连支持智能分流。在“设置” -> “路由设置”中，您可以选择“绕过局域网及中国大陆”模式。这样，只有访问海外网站时才走代理，访问国内网站（如百度、淘宝）则直接连接，实现“内外兼顾”。

**技巧二：启用UDP转发**

对于需要UDP协议的应用（如在线游戏、语音通话），请确保在“设置”中开启了“UDP转发”选项。2026版本默认启用了对QUIC协议的支持，这能显著提升视频流媒体和实时通讯应用的体验。

**技巧三：自定义DNS设置**

某些网络环境下，默认的DNS解析可能被污染，导致连接缓慢或无法访问。建议在“网络设置”中，将DNS服务器更改为公共DNS，如：
- **Google DNS**: `8.8.8.8`, `8.8.4.4`
- **Cloudflare DNS**: `1.1.1.1`, `1.0.0.1`

**技巧四：使用命令行参数（高级用户）**

快连客户端支持一些隐藏的命令行参数，用于更精细的控制。例如，在快捷方式的“目标”后添加 `--log-level=debug` 可以开启调试日志，用于排查连接故障。但请注意，非必要情况下不建议修改。

A: 请按以下步骤排查：1）检查本地网络是否正常（能否访问百度等国内网站）；2）关闭防火墙或杀毒软件（部分软件会误拦截代理连接）；3）更换节点，尝试连接其他地区的节点；4）检查系统时间是否正确（代理协议对时间误差敏感，误差超过3分钟通常会导致认证失败）。

**Q4: 使用快连会影响我的网速吗？**
A: 理论上，代理过程会增加一次数据中转和加解密操作，会引入少量延迟（通常为10-50ms）。但快连通过智能路由和高效协议，对于海外访问，其速度通常远快于直连。对于国内网站，建议开启“绕过局域网及中国大陆”模式，以避免不必要的减速。

A: 您需要登录快连官网（https://www.kuailiansj.com）的账户后台，在“我的订阅”页面选择“续费”或“升级套餐”。购买新套餐后，流量会立即重置。请注意，部分套餐支持流量叠加。

**Q6: 如何设置开机自启？**
