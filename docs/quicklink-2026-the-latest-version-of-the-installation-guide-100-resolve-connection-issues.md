## 二、核心概念

### 2.1 概念定义

在深入安装指南之前，我们需要明确几个关键概念，这将帮助您更好地理解快连的工作机制。

- **VPN（虚拟专用网络）与代理（Proxy）**：虽然快连常被归类为VPN工具，但它在技术实现上融合了VPN的加密隧道技术和代理的协议灵活性。快连通过创建一个加密的虚拟通道，将您的设备流量安全地传输到位于其他地区的服务器节点，从而隐藏真实IP地址并突破访问限制。
- **节点（Node）**：指分布在全球各地的服务器。快连拥有覆盖亚洲、美洲、欧洲、大洋洲等主要区域的数千个节点。每个节点都有独立的IP地址、带宽和延迟特性。
- **协议（Protocol）**：指数据传输的规则。快连支持多种协议，如OpenVPN、WireGuard、Shadowsocks以及其自研的专属协议。不同协议在加密强度、传输速度和抗干扰能力上各有侧重。
- **智能分流（Smart Routing）**：这是快连的核心功能之一。它能够自动识别您的流量目的地，仅对需要加速或解锁的境外流量进行代理，而国内网站、银行、购物等流量则直连本地网络，从而在保证速度的同时，不影响本地服务的正常使用。

### 2.2 工作原理

快连的工作原理可以概括为“建立隧道、加密传输、智能分发”。

1.  **连接建立**：当您在客户端点击“连接”按钮时，客户端会向快连的后端服务器发送认证请求。验证通过后，系统会根据您当前的地理位置、网络延迟和服务器负载，通过算法为您推荐一个最优的节点。
2.  **隧道封装**：客户端与选定的节点之间建立一条加密的“隧道”。所有从您设备发出的网络数据包都会被封装在这个隧道中，并使用高强度加密算法（如AES-256-GCM）进行加密，确保数据在传输过程中不被窃听或篡改。
3.  **数据传输**：加密后的数据包通过公网传输到快连节点。节点解密数据包，并以节点的真实IP地址向目标网站（如Google、YouTube）发起请求。
4.  **响应与回传**：目标网站将响应数据返回给快连节点，节点再次加密数据包，通过隧道回传给您的设备。客户端解密后，您的浏览器或应用即可正常显示内容。
5.  **智能分流实现**：快连客户端内置了域名规则库和IP地址库。当您访问一个网站时，客户端会查询规则库。如果该域名或IP在“需要代理”的列表中，流量将通过隧道发送；否则，流量直接通过本地网关发送。这一过程对用户完全透明，无需手动配置。

## 四、常见问题FAQ

**Q1: 为什么我下载的安装包无法运行，提示“已损坏”？**

**A:** 这通常发生在macOS系统上。macOS的Gatekeeper安全机制会阻止未签名的应用运行。请尝试以下步骤：
1.  打开“终端”（Terminal）。
2.  输入命令：`sudo spctl --master-disable` 并回车（输入密码后执行），临时关闭Gatekeeper。
3.  再次尝试运行。或者，右键点击应用 -> “打开”来绕开验证。**请注意：操作完成后建议重新开启Gatekeeper**，命令为 `sudo spctl --master-enable`。

**Q2: 连接成功后，为什么部分网站（如Netflix、Disney+）依然无法访问？**

**A:** 流媒体平台对IP地址的检测非常严格。如果您的节点IP被该平台识别为数据中心IP（而非家庭宽带IP），则会被屏蔽。解决方法：
1.  在节点列表中寻找带有“流媒体”或“家宽IP”标签的专属节点。
2.  尝试更换其他地区的节点，例如从美国西海岸切换到美国中部节点。
3.  清除浏览器缓存和Cookies，重新登录。

**Q3: 连接后网速非常慢，甚至不如不连，怎么办？**

**A:** 速度慢可能由多种原因导致，请按以下顺序排查：
1.  **更换节点**：当前节点可能负载过高或网络波动。尝试切换到延迟相近但负载更低的节点。
2.  **切换协议**：在“设置” -> “协议”中，尝试从“自动”切换到“WireGuard”或“Shadowsocks”。WireGuard通常有更快的速度，但抗干扰能力稍弱。
3.  **关闭其他占用带宽的软件**：检查后台是否有P2P下载、系统更新或云盘同步在运行。
4.  **检查本地网络**：使用 `ping 8.8.8.8` 命令测试您本地网络的丢包率和延迟。如果本地网络本身不稳定，快连也无法提升速度。

**Q4: 安卓手机上显示“连接失败”或“无法获取配置信息”？**

**A:** 这通常是网络环境或系统权限问题。
1.  **检查网络**：确保您的手机已经连接上Wi-Fi或移动数据。
2.  **清除应用数据**：前往“设置” -> “应用管理” -> “快连” -> “存储” -> “清除数据”。然后重新登录。
3.  **检查VPN权限**：在Android 10以上系统中，首次连接会弹出VPN配置请求，请务必点击“确定”。如果误点了“取消”，请前往“设置” -> “VPN”中手动删除快连的配置，然后重新连接。
4.  **关闭其他VPN**：如果手机同时开启了其他VPN或网络加速工具，请先关闭它们。

**Q5: 我的账号可以同时登录几台设备？**

**A:** 快连通常允许一个账号在多个设备上同时在线，具体数量取决于您购买的套餐。基础套餐通常支持2-3台设备，专业版或家庭版支持5-10台。您可以在官网的个人中心或客户端“我的设备”中查看和管理已登录的设备，如果超出限制，系统会提示您踢掉之前的设备。
