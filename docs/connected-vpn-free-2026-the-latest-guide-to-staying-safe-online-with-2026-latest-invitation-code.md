## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）**
VPN是一种网络技术，它允许用户通过公共网络（如互联网）建立一个临时的、加密的、点对点的连接。这个连接被称为“隧道”，所有通过隧道传输的数据都会被加密，从而防止第三方窃听或篡改。

**快连VPN**

**IP地址与DNS**
- **IP地址**：您的设备在网络中的唯一标识。VPN会隐藏您的真实IP，并分配一个VPN服务器的IP地址，从而实现匿名访问。
- **DNS（域名系统）**：将域名（如google.com）转换为IP地址的系统。快连VPN提供内置的防泄漏DNS，确保您的DNS查询也通过加密隧道进行，防止DNS劫持。

### 2.2 工作原理

快连VPN的工作流程可以概括为以下四个关键步骤：

1.  **客户端发起连接**：当您在设备上启动快连VPN并点击“连接”时，客户端软件会向快连的服务器集群发起一个加密的握手请求。这个请求包含了您的身份验证信息（如邀请码或账号密码）以及您选择的服务器节点。

2.  **建立加密隧道**：快连VPN服务器验证您的身份后，会与您的客户端协商一个加密密钥。随后，使用WireGuard（默认）或OpenVPN协议，在您的设备与服务器之间建立一条加密的“隧道”。所有后续的数据包在进入隧道前都会被加密。

3.  **数据封装与转发**：您的所有网络请求（如访问一个网页）会被封装成加密数据包，通过隧道发送给快连VPN服务器。服务器解密这些数据包，然后以服务器自身的IP地址作为源地址，向目标网站（如YouTube、Google）发起请求。目标网站看到的是快连服务器的IP，而非您的真实IP。

4.  **响应回传与解密**：目标网站的响应数据被发送回快连VPN服务器，服务器再次将其加密，通过隧道回传至您的客户端。客户端解密后，最终呈现给您。整个过程对用户而言是透明的，您感觉就像在直接访问目标网站一样流畅。

**关键安全机制**：快连VPN采用AES-256-GCM加密算法，这是目前军用级别的加密标准，理论上即使是超级计算机也需要数十亿年才能破解。同时，其“零日志”政策确保不记录您的任何浏览历史、连接时间或带宽使用情况，从根本上保护您的隐私。
