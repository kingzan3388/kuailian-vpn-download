## 二、核心概念

### 2.1 概念定义

**kuailian** 是一款基于代理与隧道技术的网络加速工具。它通过建立一条加密的、优化的传输通道，将用户的网络请求从源地址（如你的电脑或手机）转发到目标服务器（如海外网站或游戏服务器）。其核心功能包括：

- **连接加速**：通过优化路由、减少丢包和延迟，提升网络响应速度。
- **访问优化**：突破地理限制，访问全球范围内的资源。
- **数据加密**：对传输数据进行加密，保护用户隐私与安全。

在 kuailian 的语境中，**“节点”** 指的是位于不同地理位置的服务器端点，用户通过连接到这些节点来实现加速。**“协议”** 则指数据传输的规则，如 TCP、UDP 或自定义的加密协议。

### 2.2 工作原理

kuailian 的工作原理可以概括为“智能路由 + 隧道封装”。当用户发起一个网络请求（例如访问一个网站）时，kuailian 客户端会执行以下步骤：

1. **请求拦截**：客户端在操作系统层面拦截该请求，并将其重定向到本地运行的 kuailian 代理端口（通常是 1080 或 7890）。
2. **协议封装与加密**：客户端根据用户选择的协议（如 Shadowsocks、V2Ray 或 Hysteria2），将原始数据包进行封装和加密。这一步骤确保了数据在传输过程中不会被中间人窃听或篡改。
3. **智能节点选择**：kuailian 内置的“智能路由引擎”会实时分析所有可用节点的延迟、丢包率和带宽状况。它会自动选择当前最优的节点（例如，延迟最低或距离最近）来转发请求。
4. **隧道传输**：加密后的数据通过该节点建立的隧道，经过互联网传输到目标服务器。由于隧道经过了优化，它能够绕过网络拥塞点，并避免被网络防火墙的深度包检测（DPI）识别。
5. **数据解密与转发**：节点服务器接收到数据后，会对其进行解密，恢复成原始的请求格式，并转发给真正的目标服务器。
6. **响应返回**：目标服务器的响应数据沿相同路径反向返回，最终到达用户的浏览器或应用程序。整个过程对用户几乎透明，用户感受到的只是更快的加载速度和更稳定的连接。

这种机制使得 kuailian 能够在复杂网络环境下，提供比直连更稳定、更快速的连接体验。

## 三、使用指南

### 3.1 安装配置

#### 3.1.1 系统要求
- **操作系统**：Windows 10/11、macOS 10.15+、Ubuntu 20.04+ 或 Android 8.0+ / iOS 14.0+
- **硬件**：至少 1GB 内存、500MB 可用磁盘空间
- **网络**：稳定的互联网连接

#### 3.1.2 下载与安装
1. 访问 kuailian 官方网站 [https://www.kuailiansj.com](https://www.kuailiansj.com)，在“下载”页面选择对应操作系统的安装包。
2. **Windows 用户**：双击 `.exe` 文件，按照安装向导完成安装。安装完成后，桌面会出现 kuailian 图标。
3. **macOS 用户**：打开 `.dmg` 文件，将 kuailian 图标拖入“应用程序”文件夹。
4. **Linux 用户**：解压 `.tar.gz` 文件，运行 `./kuailian` 启动客户端。

#### 3.1.3 初始配置
1. 启动 kuailian 客户端，界面会提示输入“订阅链接”或“手动添加节点”。
2. **订阅方式（推荐）**：如果你已购买套餐，登录官网后，在“仪表盘”中找到“订阅链接”。复制该链接，粘贴到客户端的“订阅管理”输入框中，点击“更新订阅”。客户端会自动拉取所有可用节点。
3. **手动添加**：若你拥有单个节点的 IP、端口、密码和加密方式，可在“节点管理”中点击“添加”，逐一填写。
4. 配置完成后，在节点列表中选择一个延迟较低的节点（通常绿色标记表示延迟低），点击“启用”或“连接”按钮。

### 3.2 基本用法

#### 3.2.1 连接与断开
- **连接**：在客户端主界面，点击“连接”按钮。状态指示灯变为绿色，表示连接成功。
- **断开**：再次点击“连接”按钮，或右键点击系统托盘图标选择“断开”。

#### 3.2.2 模式选择
kuailian 提供三种运行模式：
- **全局模式**：所有网络请求都通过 kuailian 代理。适合访问海外网站或需要稳定连接的应用。
- **规则模式**：根据预设规则（如国内网站直连、海外网站代理）自动分流。这是最常用的模式，兼顾速度与效率。
- **绕过局域网**：局域网内的设备（如打印机、NAS）不通过代理。

#### 3.2.3 测试连接
连接后，建议进行以下测试：
- **延迟测试**：在客户端“节点列表”中，点击每个节点的“延迟测试”按钮，查看响应时间。
- **速度测试**：访问 [fast.com](https://fast.com) 或 [speedtest.net](https://speedtest.net)，对比直连与代理后的速度差异。
- **IP 检测**：访问 [ipinfo.io](https://ipinfo.io)，确认 IP 地址已变为节点所在地区。

### 3.3 高级技巧

#### 3.3.1 自定义规则
如果你熟悉路由规则，可以编辑客户端的规则文件（通常位于 `config/rules.yaml`）。例如，强制让特定域名走代理：
```yaml
# 强制 Netflix 走代理
rules:
  - DOMAIN-SUFFIX,netflix.com,PROXY
  - DOMAIN-SUFFIX,netflix.net,PROXY
```
保存后，重启客户端使规则生效。

#### 3.3.2 多节点负载均衡
在“连接设置”中，可以启用“负载均衡”模式。该模式允许同时连接多个节点，并根据实时性能（如最低延迟或最低丢包）自动切换。设置方法：
1. 在“节点列表”中，按住 `Ctrl` 键（Mac 为 `Cmd`）选择多个节点。
2. 右键点击，选择“添加到负载均衡组”。
3. 在“设置”中，选择“负载均衡”为默认模式。

#### 3.3.3 解决 DNS 污染
DNS 污染是导致连接失败的主要原因之一。kuailian 内置了“远程 DNS”功能：
1. 进入“设置” > “DNS 设置”。
2. 勾选“启用远程 DNS 解析”。
3. 选择“使用节点 DNS”或“自定义 DNS”（推荐使用 `8.8.8.8` 或 `1.1.1.1`）。
4. 保存设置并重新连接。

此设置可确保域名解析不被本地网络干扰，从而解决部分网站无法访问的问题。

## 四、常见问题FAQ

### 4.1 为什么连接后无法访问某些网站？
**解答**：这通常由以下原因导致：
- **DNS 污染**：请确保已启用远程 DNS（参考 3.3.3 节）。
- **规则冲突**：检查是否使用了“规则模式”，某些规则可能错误地将目标网站归为“直连”。尝试切换到“全局模式”测试。
- **节点问题**：该节点可能被目标网站封锁。尝试更换其他节点。
- **协议兼容性**：某些网站（如银行、支付平台）会检测代理。尝试使用“伪装协议”（如 WebSocket 或 TLS）。

### 4.2 连接速度很慢，如何进行优化？
**解答**：
1. **更换节点**：选择延迟更低、带宽更高的节点。在客户端中，按“延迟”或“速度”排序节点。
2. **调整加密方式**：在节点设置中，将加密方式改为 `chacha20-ietf-poly1305` 或 `none`（不推荐），以降低 CPU 负载。
3. **启用 TCP 加速**：在“高级设置”中，开启“TCP 快速打开”和“BBR 拥塞控制”（如果系统支持）。
4. **检查本地网络**：确保其他应用（如下载工具）未占用大量带宽。

### 4.3 客户端提示“连接超时”或“握手失败”怎么办？
**解答**：
- **检查网络连通性**：尝试 ping 节点的 IP 地址（如 `ping 192.168.1.1`）。如果超时，说明本地网络或节点本身不可达。
- **更换协议**：某些网络环境（如公司防火墙）会屏蔽特定协议。尝试将协议从 `TCP` 切换为 `UDP` 或 `WebSocket`。
- **更新客户端**：访问官网 [https://www.kuailiansj.com](https://www.kuailiansj.com) 下载最新版本，旧版本可能存在兼容性问题。
- **检查防火墙**：确保 Windows 防火墙或杀毒软件未拦截 kuailian 的进程。

### 4.4 如何在不同设备间同步配置？
**解答**：kuailian 支持“云端配置同步”功能：
1. 在客户端中登录你的账户（官网注册的账号）。
2. 进入“设置” > “同步”。
3. 点击“上传配置”将当前设置保存到云端。
4. 在其他设备上登录同一账号，点击“下载配置”即可同步。

### 4.5 订阅链接失效或节点无法更新怎么办？
**解答**：
- **检查订阅链接是否过期**：登录官网，查看订阅状态。如果已过期，需要续费。
- **手动更新**：在客户端“订阅管理”中，点击“更新订阅”按钮。如果失败，尝试删除当前订阅，重新添加。
- **使用备用链接**：部分套餐提供多个订阅链接（如主链接和备用链接），尝试更换。
- **联系客服**：如果以上方法无效，通过官网的“在线客服”或工单系统寻求帮助。

### 4.6 启动 kuailian 后，其他网络应用（如游戏、聊天软件）无法正常工作？
**解答**：
- **检查模式设置**：对于游戏和聊天软件，建议使用“规则模式”并确保其域名被正确分流。某些游戏（如《英雄联盟》）需要 UDP 支持，请在节点设置中确保 UDP 代理已启用。
- **关闭“全局模式”**：全局模式会强制所有流量走代理，可能导致本地服务（如打印机、局域网共享）中断。
- **添加排除规则**：在“规则”设置中，添加 `DOMAIN-SUFFIX,local,REJECT` 或 `IP-CIDR,192.168.0.0/16,DIRECT`，让局域网流量直连。
