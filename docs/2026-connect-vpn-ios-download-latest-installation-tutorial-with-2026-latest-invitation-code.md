### 2.1 概念定义

**快连VPN** 本质上是一种基于虚拟专用网络（VPN）技术的网络服务。VPN（Virtual Private Network）通过在你的设备（如iPhone）与远程服务器之间建立一条加密的、专用的“隧道”，将你的所有网络流量通过该隧道传输。这样一来，你的真实IP地址被隐藏，取而代之的是VPN服务器的IP地址；同时，所有传输的数据都经过高强度加密，即使被第三方截获，也无法解读其内容。

**关键术语解释：**
- **节点/服务器**：快连VPN在全球范围内部署的物理或虚拟服务器。用户可以选择连接不同国家的节点，从而获得该国家的IP地址。
- **协议**：VPN用于建立加密隧道的通信规则。常见的协议包括OpenVPN、WireGuard、IKEv2等。快连VPN通常支持多种协议以适应不同网络环境。
- **DNS泄漏**：当VPN连接出现故障时，设备可能依然使用本地DNS服务器解析域名，导致真实IP暴露。快连VPN内置了防泄漏机制。
