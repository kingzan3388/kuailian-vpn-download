## 二、核心概念

### 2.1 概念定义

**快连VPN** 是一种基于现代VPN协议（如WireGuard、OpenVPN及专有协议）的加密隧道服务。其核心功能是：在用户的设备（客户端）与目标服务器（节点）之间建立一个加密的、安全的逻辑通道。所有通过此通道传输的数据都会经过高强度加密，从而有效防止ISP（互联网服务提供商）、黑客或任何第三方进行窃听、篡改或流量分析。

与传统的VPN不同，快连VPN在2026年版本中引入了**智能分流**与**动态多路径**技术。智能分流允许用户自定义哪些流量走VPN隧道（例如访问特定网站），哪些流量直连本地网络（例如访问本地银行或外卖平台），从而在保障隐私的同时最大化访问速度。动态多路径技术则能在网络抖动时，自动在UDP、TCP及QUIC协议间切换，确保连接的稳定性。

### 2.2 工作原理

理解快连VPN的工作机制有助于更好地使用它。其工作流程可简化为以下四个步骤：

1.  **连接建立**：用户在客户端点击“连接”按钮后，客户端向快连VPN的协调服务器发起认证请求。认证通过后，协调服务器会分配一个延迟最低、负载最轻的节点地址给客户端。
2.  **隧道封装**：客户端与指定节点之间通过**WireGuard**或**OpenVPN**协议握手，交换密钥。随后，所有本地发出的网络数据包被封装在一个新的IP数据包中，其源地址为客户端的虚拟IP，目的地址为节点的真实IP。
3.  **加密传输**：封装后的数据包使用**ChaCha20-Poly1305**（WireGuard默认）或**AES-256-GCM**（OpenVPN）等现代加密算法进行加密。即使数据在公网上被截获，攻击者也仅能看到乱码。
4.  **解包与转发**：节点收到加密数据包后，使用私钥解密，还原出原始数据包。节点根据原始数据包的目标地址（例如 `www.google.com`）将其转发到公网。响应数据返回时，节点再执行反向操作，将数据加密并通过隧道发回客户端。

**关键点**：在这一过程中，你的真实IP地址被节点的IP地址所替代，因此目标服务器看到的是节点的IP，从而实现了IP隐藏和地域解锁。

    -   点击选中的节点旁的“连接”按钮。

3.  **验证连接**：

4.  **断开连接**：
    -   点击主界面的“断开”按钮，或直接关闭应用。此时网络流量将恢复为直连模式。

    -   **添加代理规则**：如果你只想让特定程序（如Steam、游戏客户端）走VPN，可以添加“进程名称”规则，输入 `steam.exe`，并设置为“代理”。

-   **优化协议选择**：

-   **命令行操作（Linux/高级用户）**：

## 四、常见问题FAQ

**Q1: 为什么连接成功后，部分网站仍然无法访问？**
**A:** 这通常由DNS泄漏或分流规则冲突导致。请尝试以下步骤：
1.  在快连VPN设置中启用“防DNS泄漏”功能。
2.  检查“规则管理”中是否错误地将该网站加入了“直连”列表。
3.  尝试使用“全局模式”而非“智能分流模式”进行测试。如果全局模式正常，则说明是分流规则问题。

**Q2: 快连VPN在2026年是否支持IPv6？**
**A:** 是的，快连VPN在2026版中已全面支持IPv6。默认情况下，客户端会优先使用IPv6地址进行隧道连接，以获得更低延迟。如果网络环境不支持IPv6，系统会自动回退到IPv4。你可以在“设置” -> “网络”中手动禁用IPv6。

**Q3: 连接后网速很慢，如何排查？**
**A:** 慢速通常由以下原因导致：
1.  **节点负载过高**：切换到其他节点或使用“负载均衡”模式。
2.  **协议选择不当**：尝试从WireGuard切换到OpenVPN TCP，或反之。
3.  **本地网络问题**：断开VPN，测试直连速度。如果直连也慢，说明是本地ISP问题。
4.  **MTU设置**：在高级设置中，将MTU值从1500调整为1400或1200，测试效果。

**Q4: 如何在不同设备间同步配置？**
**A:** 快连VPN支持云端配置同步。登录同一账号后，所有设备的“分流规则”、“自定义DNS”和“收藏节点”会自动同步。如果同步失败，请检查设备是否已连接到互联网，并在“账户”中点击“手动同步”。

**Q5: 快连VPN的日志政策是怎样的？**
**A:** 快连VPN严格执行**无日志政策**（No-Log Policy）。这意味着我们不会记录你的浏览历史、连接时间、流量内容或DNS查询记录。仅会收集必要的匿名诊断数据（如连接失败次数）以优化服务质量。该政策已通过第三方审计，审计报告可在官网查阅。

**Q6: 在路由器上安装快连VPN后，为何无法访问本地NAS？**
**A:** 这是因为路由器的VPN开启了“全流量代理”，导致访问内网IP的流量也被路由到了VPN节点。解决方案：在路由器的快连VPN管理界面中，添加“绕过代理”规则，将你的NAS的IP地址（如`192.168.1.100`）加入“Bypass”列表。
