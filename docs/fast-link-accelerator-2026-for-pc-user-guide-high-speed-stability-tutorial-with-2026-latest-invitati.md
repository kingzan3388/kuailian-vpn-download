## 二、核心概念

### 2.1 概念定义

要理解快连加速器的工作原理，首先需要明确几个核心概念：

- **网络延迟（Latency）**：指数据从用户设备发送到目标服务器并返回的总时间，通常以毫秒（ms）为单位。低延迟是实时交互应用（如在线游戏、视频会议）的关键。
- **丢包率（Packet Loss）**：数据在传输过程中丢失的比例。高丢包率会导致画面卡顿、语音断续或连接中断。
- **带宽（Bandwidth）**：单位时间内能够传输的数据量，通常以Mbps（兆比特每秒）衡量。高带宽是高清视频流和大文件下载的保障。
- **节点（Node）**：快连加速器在全球各地部署的服务器，用户通过连接这些节点来优化网络路径。节点质量（如出口带宽、CPU性能）直接影响加速效果。
- **协议（Protocol）**：数据传输的规则和标准。快连加速器支持多种协议（如TCP、UDP、以及自研的KCP协议），以适应不同网络环境。

快连加速器的核心价值在于，它不直接“改变”用户的物理网络，而是通过在中转节点上对数据进行“封装”和“重路由”，避开拥堵或受限的路径，从而显著降低延迟和丢包率。

### 2.2 工作原理

快连加速器PC版的工作流程可以概括为“感知-选择-传输”三步：

2. **智能路由选择**：基于感知到的数据，快连加速器采用一种“多目标优化算法”来决定最佳节点和传输路径。该算法并非单纯追求最低延迟，而是综合考量延迟、丢包率、节点负载和用户目标服务器所在区域。例如，当用户访问一个位于美国的游戏服务器时，算法会优先选择一条从用户到美国西海岸节点、再到游戏服务器延迟最低且丢包率最小的路径。如果某个节点出现拥堵，系统会毫秒级自动切换到备用节点。

3. **数据封装与传输**：一旦选定节点，所有用户数据（如游戏数据包、网页请求）都会被快连加速器客户端进行加密和封装，形成一个“隧道”数据包。这个隧道数据包通过用户本地的网络连接发送到选定的加速节点。节点接收到后，会进行解封装、解密，然后将原始数据以最优路径转发到目标服务器。反之，从目标服务器返回的数据也会经过节点加密后传回用户端。这种机制不仅实现了加速，还提供了额外的数据安全保护，防止中间人攻击。
