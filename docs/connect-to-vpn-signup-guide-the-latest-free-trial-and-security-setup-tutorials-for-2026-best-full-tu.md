## 二、核心概念

### 2.1 概念定义

**VPN（虚拟专用网络）** 是一种通过公共网络（如互联网）建立专用、加密通信隧道的技术。它允许用户将设备（电脑、手机、路由器）连接到远程服务器，所有网络流量均通过该隧道传输，从而在公共网络上创建一个安全的“虚拟专用”网络。关键组件包括：
- **加密协议**：如OpenVPN、WireGuard、IKEv2，负责数据加密与认证。
- **隧道协议**：封装原始数据包，确保其在公共网络中的隐蔽传输。
- **远程服务器**：VPN服务商在全球部署的节点，用户连接后，其IP地址会被替换为服务器IP。

**快连VPN** 在此基础上优化了协议栈，采用多线程并发与智能路由算法，在保证安全性的同时，显著提升连接速度和稳定性。其核心优势包括：
- **零日志政策**：不记录用户浏览历史、连接时间或带宽使用量，符合GDPR等隐私法规。
- **多平台支持**：提供Windows、macOS、iOS、Android、Linux客户端及浏览器扩展。
- **动态节点分配**：根据用户地理位置自动分配最优节点，降低延迟。

### 2.2 工作原理

快连VPN的工作流程可分为以下几个步骤：

1. **客户端初始化**：用户启动快连VPN客户端，输入账号密码（或使用注册时生成的密钥）进行身份验证。客户端会向服务端发送连接请求，协商加密参数（如密钥交换算法、对称加密算法）。
2. **隧道建立**：客户端与快连VPN服务器之间通过握手协议（如TLS 1.3）建立加密隧道。此过程中，所有数据包都会被封装在隧道协议中，原始数据包的源IP、目标IP、端口等信息均被隐藏。
3. **流量转发**：用户设备的所有网络流量（包括HTTP/HTTPS请求、DNS查询、P2P数据）都被重定向至本地虚拟网卡，经过加密后发送至快连VPN服务器。服务器解密后，将请求转发至目标互联网资源（如网站、流媒体平台），并将响应数据加密后返回给客户端。
4. **IP伪装**：目标服务器看到的请求来源IP是快连VPN服务器的IP，而非用户的真实IP。这样，用户的地理位置、ISP信息、设备标识均被隐藏，实现匿名访问。
5. **安全机制**：快连VPN采用**分割隧道**（Split Tunneling）技术，允许用户自定义哪些应用或流量走VPN通道，哪些走本地网络。同时，内置**DNS泄漏保护**和**IPv6泄漏保护**，防止真实IP通过其他协议泄露。
