### 2.2 工作原理

快连的工作原理基于客户端-服务器架构：
1. **加密隧道建立**：客户端与服务器通过握手协议交换密钥，创建加密通道。

4. **响应回传**：目标网站响应数据沿相同路径加密返回客户端。
