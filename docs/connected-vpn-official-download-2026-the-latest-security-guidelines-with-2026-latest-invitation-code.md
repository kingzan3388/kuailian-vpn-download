## 二、核心概念

### 2.1 概念定义

**虚拟专用网络 (VPN)** 是一种通过在公共网络（如互联网）上建立加密隧道，实现远程网络之间安全通信的技术。其核心功能包括：

*   **数据加密：** 将用户设备发出的所有网络流量进行加密处理，即使数据被第三方截获，也无法读取实际内容。
*   **IP地址隐藏：** 将用户的真实IP地址替换为VPN服务器的IP地址，从而隐藏用户的地理位置和网络身份。
*   **隧道协议：** 使用特定协议（如OpenVPN、WireGuard、IKEv2）建立客户端与服务器之间的安全连接通道。
